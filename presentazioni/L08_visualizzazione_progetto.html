Parte 1 — Matplotlib

La libreria di visualizzazione di riferimento

Istogramma

Visualizza la distribuzione di una variabile continua.

import matplotlib.pyplot as plt
import numpy as np

rng: np.random.Generator = np.random.default_rng(seed=42)
altezze: np.ndarray = rng.normal(loc=170, scale=10, size=500)

fig, ax = plt.subplots(figsize=(8, 5))
ax.hist(altezze, bins=25, color="steelblue",
        edgecolor="white", alpha=0.8)
ax.set_title("Distribuzione delle altezze")
ax.set_xlabel("Altezza (cm)")
ax.set_ylabel("Frequenza")
plt.tight_layout()
plt.savefig("istogramma_altezze.png", dpi=150)
plt.show()
Parametri chiave: bins controlla il numero di barre; alpha la trasparenza (0–1); edgecolor il bordo delle barre.

Scatter plot

Mostra la relazione tra due variabili continue.

import matplotlib.pyplot as plt

Quando usarlo: per esplorare correlazioni e individuare pattern, outlier o cluster.

Grafico a barre

Confronta valori tra categorie discrete.

import matplotlib.pyplot as plt

corsi: list[str] = ["Statistica", "Economia", "Sociologia", "Informatica"]
media_voti: list[float] = [26.3, 24.8, 25.1, 27.2]

fig, ax = plt.subplots(figsize=(8, 5))
colori = ["#4C72B0", "#55A868", "#C44E52", "#8172B2"]
barre = ax.bar(corsi, media_voti, color=colori,
               edgecolor="black", width=0.6)

# Etichette sopra le barre
for barra, valore in zip(barre, media_voti):
    ax.text(barra.get_x() + barra.get_width() / 2,
            barra.get_height() + 0.1,
            f"{valore:.1f}", ha="center", va="bottom")

ax.set_title("Voto medio per corso di laurea")
ax.set_ylabel("Voto medio")
ax.set_ylim(22, 29)
plt.tight_layout()
plt.savefig("barre_corsi.png", dpi=150)
plt.show()

Istogramma vs grafico a barre

Istogramma

  • Variabile continua
  • Mostra la distribuzione
  • Le barre sono adiacenti
  • L'asse x ha un ordine naturale
  • Es: distribuzione delle altezze

Grafico a barre

  • Variabile categoriale
  • Confronta valori tra gruppi
  • Le barre sono separate
  • L'asse x sono etichette
  • Es: voto medio per corso
Errore comune: usare un grafico a barre per mostrare una distribuzione, o un istogramma per confrontare categorie. La scelta del grafico sbagliato comunica informazioni sbagliate.

Regola d'oro: un grafico senza etichette e un grafico inutile. Titolo, assi, legenda, unita di misura: ogni grafico deve essere comprensibile da solo.

plt.plot() vs ax.plot()

Interfaccia implicita

plt.plot(x, y)
plt.title("Titolo")
plt.xlabel("X")
plt.show()

Funziona su una figura "nascosta". Problematico con piu grafici.

Interfaccia esplicita

fig, ax = plt.subplots()
ax.plot(x, y)
ax.set_title("Titolo")
ax.set_xlabel("X")
plt.show()

Controllo esplicito su figura e assi. Scalabile a piu pannelli.

Consiglio: usate sempre fig, ax = plt.subplots(). E piu esplicito, piu flessibile, e si estende naturalmente ai subplots.

Seaborn: boxplot per confronto gruppi

Seaborn lavora direttamente con i DataFrame Pandas.

import seaborn as sns
import matplotlib.pyplot as plt
import pandas as pd

fig, ax = plt.subplots(figsize=(9, 5))
sns.boxplot(data=df, x="corso", y="voto",
            palette="Set2", ax=ax)
ax.set_title("Distribuzione dei voti per corso", fontsize=14)
ax.set_xlabel("Corso di laurea")
ax.set_ylabel("Voto medio")
plt.tight_layout()
plt.savefig("boxplot_voti_corso.png", dpi=150)
plt.show()
Anatomia del boxplot:
  • Linea centrale: mediana (Q2)
  • Bordi della scatola: Q1 (25%) e Q3 (75%)
  • Baffi: fino a 1.5 × IQR dai bordi
  • Punti isolati: outlier (oltre i baffi)

Seaborn: heatmap della correlazione

import seaborn as sns
import matplotlib.pyplot as plt

colonne_numeriche = ["voto", "ore_studio", "eta", "stipendio_atteso"]
matrice_corr: pd.DataFrame = df[colonne_numeriche].corr()

fig, ax = plt.subplots(figsize=(7, 6))
sns.heatmap(
    matrice_corr,
    annot=True,          # mostra i valori nelle celle
    fmt=".2f",           # due decimali
    cmap="coolwarm",     # scala di colori
    center=0,            # centro della scala
    square=True,         # celle quadrate
    linewidths=1,        # griglia tra le celle
    ax=ax
)
ax.set_title("Matrice di correlazione", fontsize=14)
plt.tight_layout()
plt.savefig("heatmap_correlazione.png", dpi=150)
plt.show()
Nota: la diagonale e sempre 1.0 (correlazione di una variabile con se stessa). Un valore vicino a 0 indica assenza di relazione lineare.

Subplots: creare una dashboard

Combinare piu grafici in una singola figura con plt.subplots(righe, colonne).

fig, axes = plt.subplots(2, 2, figsize=(14, 10))
fig.suptitle("Dashboard: analisi studenti universitari",
             fontsize=16, fontweight="bold", y=1.02)

# Pannello 1: istogramma dei voti
axes[0, 0].hist(df["voto"], bins=20, color="steelblue",
                edgecolor="white", alpha=0.8)
axes[0, 0].set_title("Distribuzione dei voti")

# Pannello 2: boxplot per corso
sns.boxplot(data=df, x="corso", y="voto",
            palette="Set2", ax=axes[0, 1])

# Pannello 3: scatter ore studio vs voto
axes[1, 0].scatter(df["ore_studio"], df["voto"],
                   alpha=0.4, color="coral", s=20)

# Pannello 4: conteggio per corso (barre)
conteggi = df["corso"].value_counts()
axes[1, 1].bar(conteggi.index, conteggi.values,
               color=["#4C72B0", "#55A868", "#C44E52", "#8172B2"])

plt.tight_layout()
plt.savefig("dashboard.png", dpi=150, bbox_inches="tight")

Dettagli importanti

plt.tight_layout()

Regola automaticamente i margini per evitare sovrapposizioni tra titoli, etichette e pannelli.

Senza tight_layout(), i subplots si sovrappongono facilmente.

plt.savefig()

ParametroUso
dpi=150Risoluzione (150 per schermo, 300 per stampa)
bbox_inches="tight"Taglia i margini vuoti
transparent=TrueSfondo trasparente
Ordine corretto: tight_layout() → savefig() → show(). Se chiamate show() prima di savefig(), il file salvato potrebbe essere vuoto.

Il parametro alpha

Controlla la trasparenza degli elementi grafici (0 = invisibile, 1 = opaco).

# Senza trasparenza
ax.scatter(x, y, alpha=1.0)
# I punti sovrapposti si coprono
# Con trasparenza
ax.scatter(x, y, alpha=0.4)
# Si vedono le zone dense
Quando e utile:
  • Scatter plot con molti punti: alpha=0.3–0.5 per vedere la densita
  • Istogrammi sovrapposti: alpha=0.5–0.7 per confrontare distribuzioni
  • Grafici a linee multiple: alpha=0.8 per distinguere le linee

Passo 2 — Esplorazione

def esplora_dataset(df: pd.DataFrame) -> None:
    """Stampa un riepilogo esplorativo del dataset.

    Mostra: dimensioni, tipi delle colonne, prime righe,
    statistiche descrittive, conteggio valori per ogni
    colonna categoriale, conteggio valori mancanti.
    """
    print(f"Dimensioni: {df.shape}")
    print(f"\n=== TIPI ===\n{df.dtypes}")
    print(f"\n=== HEAD ===\n{df.head()}")
    print(f"\n=== DESCRIBE ===\n{df.describe()}")

    for col in df.select_dtypes(include="object").columns:
        print(f"\n=== {col.upper()} ===")
        print(df[col].value_counts())

    print(f"\n=== MANCANTI ===\n{df.isnull().sum()}")
Regola: esplorate sempre i dati prima di analizzarli. Un head(), un describe(), un istogramma: bastano pochi secondi per evitare ore di lavoro su dati sbagliati.

Passo 3 — Pulizia

Inserite intenzionalmente dei difetti, poi correggeteli:

def pulisci_dataset(df: pd.DataFrame) -> pd.DataFrame:
    """Pulisce il dataset: gestisce mancanti, anomali,
    inconsistenze.

    Strategia:
    - Stipendio mancante: mediana del settore.
    - Ore settimanali > 80 o < 5: sostituite con mediana.
    - Stringhe: normalizzate con strip() e capitalize().
    """
    df_pulito: pd.DataFrame = df.copy()

    # Normalizzare stringhe
    for col in ["settore", "ruolo", "regione"]:
        df_pulito[col] = (df_pulito[col]
                          .str.strip()
                          .str.capitalize())

    # Stipendio mancante -> mediana per settore
    df_pulito["stipendio"] = (
        df_pulito.groupby("settore")["stipendio"]
        .transform(lambda s: s.fillna(s.median()))
    )

    # Ore anomale -> mediana generale
    mediana_ore = df_pulito["ore_settimanali"].median()
    anomale = (df_pulito["ore_settimanali"] > 80) | \
              (df_pulito["ore_settimanali"] < 5)
    df_pulito.loc[anomale, "ore_settimanali"] = mediana_ore

    return df_pulito

Passo 4 — Analisi per gruppi

def analisi_per_gruppi(df: pd.DataFrame) -> dict[str, pd.DataFrame]:
    """Calcola statistiche aggregate per diversi raggruppamenti."""
    risultati: dict[str, pd.DataFrame] = {}

    # Stipendio medio e mediano per settore
    risultati["stipendio_per_settore"] = (
        df.groupby("settore")["stipendio"]
        .agg(["mean", "median"]).round(0)
    )

    # Soddisfazione media per ruolo
    risultati["soddisfazione_per_ruolo"] = (
        df.groupby("ruolo")["soddisfazione"]
        .mean().round(2)
    )

    # Pivot table: stipendio medio per settore e ruolo
    risultati["pivot_stipendio"] = pd.pivot_table(
        df, values="stipendio",
        index="settore", columns="ruolo",
        aggfunc="mean"
    ).round(0)

    # Correlazione
    cols = ["anni_esperienza", "stipendio", "soddisfazione"]
    risultati["correlazione"] = df[cols].corr().round(3)

    return risultati

Passo 5 — Dashboard di visualizzazione

def crea_dashboard(df: pd.DataFrame,
                   percorso_output: str) -> None:
    """Crea una dashboard con 4 grafici e la salva."""
    fig, axes = plt.subplots(2, 2, figsize=(14, 10))
    fig.suptitle("Dashboard dipendenti", fontsize=16,
                 fontweight="bold")

    # 1. Istogramma stipendi
    axes[0,0].hist(df["stipendio"], bins=30,
                   color="steelblue", edgecolor="white")
    axes[0,0].set_title("Distribuzione stipendi")

    # 2. Boxplot stipendi per settore
    sns.boxplot(data=df, x="settore", y="stipendio",
                palette="Set2", ax=axes[0,1])
    axes[0,1].tick_params(axis="x", rotation=30)

    # 3. Scatter esperienza vs stipendio
    for settore in df["settore"].unique():
        mask = df["settore"] == settore
        axes[1,0].scatter(df.loc[mask, "anni_esperienza"],
                          df.loc[mask, "stipendio"],
                          alpha=0.4, s=20, label=settore)
    axes[1,0].legend(fontsize=8)

    # 4. Heatmap correlazione
    cols_num = df.select_dtypes(include="number").columns
    sns.heatmap(df[cols_num].corr(), annot=True, fmt=".2f",
                cmap="coolwarm", center=0, ax=axes[1,1])

    plt.tight_layout()
    plt.savefig(percorso_output, dpi=150, bbox_inches="tight")

Struttura del programma principale

import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
import seaborn as sns

# ... definizioni delle funzioni sopra ...

def main() -> None:
    """Funzione principale: esegue l'analisi completa."""
    percorso_csv: str = "dipendenti.csv"

    # 1. Generazione
    df: pd.DataFrame = genera_dataset(500, percorso_csv)
    # 2. Caricamento (dimostra il ciclo salva/carica)
    df = carica_dataset(percorso_csv)
    # 3. Esplorazione
    esplora_dataset(df)
    # 4. Pulizia
    df_pulito: pd.DataFrame = pulisci_dataset(df)
    # 5. Analisi
    risultati = analisi_per_gruppi(df_pulito)
    for nome, tabella in risultati.items():
        print(f"\n{'=' * 50}")
        print(f"  {nome}")
        print(f"{'=' * 50}")
        print(tabella)
    # 6. Visualizzazione
    crea_dashboard(df_pulito, "dashboard_dipendenti.png")
    # 7. Export
    df_pulito.to_csv("dipendenti_pulito.csv", index=False)

if __name__ == "__main__":
    main()

Interpretazione dei risultati

Dopo aver completato il progetto, rispondete per iscritto:

  1. Quale settore ha lo stipendio medio piu alto? E anche quello con la soddisfazione piu alta?

  3. Dalla heatmap, quali coppie di variabili sono piu correlate? Quali sono indipendenti?
