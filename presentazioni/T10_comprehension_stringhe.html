Soluzione · laboratorio 1

area_cerchio.py

import math

raggio: float = float(input("Raggio del cerchio (cm): "))

area: float = math.pi * raggio ** 2
circonferenza: float = 2 * math.pi * raggio

print("--- Risultati ---")
print(f"Raggio: {raggio:.2f} cm")
print(f"Area: {area:.2f} cm²")
print(f"Circonferenza: {circonferenza:.2f} cm")
  • import math va in cima al file: senza, math.pi dà NameError.
  • raggio ** 2 si calcola prima della moltiplicazione per math.pi.
  • math.pi è più preciso di 3.14: con raggio 5 l'area è 78.54, con 3.14 sarebbe 78.50.
⏱ 2' · blocco «Soluzioni L01» Da dire: stesso schema di tutti i programmi di oggi: lettura con float(), calcolo, stampa. Le formule sono quelle di geometria: area = pi per r al quadrato, circonferenza = 2 pi r. Chiedere / fare: con raggio 5 deve uscire area 78.54 e circonferenza 31.42. Chi ha usato 3.14 invece di math.pi? Quanto cambia il risultato?

imc.py

peso: float = float(input("Peso (kg): "))
altezza: float = float(input("Altezza (m): "))

if peso <= 0 or altezza <= 0:
    print("Errore: peso e altezza devono essere positivi")
elif altezza > 2.50:
    print("Errore: l'altezza non può superare 2.50 m")
else:
    imc: float = peso / altezza ** 2

    if imc < 18.5:
        classe: str = "Sottopeso"
    elif imc < 25:
        classe = "Normopeso"
    elif imc < 30:
        classe = "Sovrappeso"
    else:
        classe = "Obesità"

    print(f"IMC: {imc:.1f} — {classe}")
  • Prima si controllano i dati, poi si calcola: con altezza 0 la divisione darebbe ZeroDivisionError.
  • Nella catena elif basta il limite superiore: se si arriva a imc < 25, imc è già almeno 18.5.
  • altezza ** 2 viene calcolato prima della divisione.
⏱ 3' · blocco «Soluzioni L01» Da dire: la validazione sta in testa; il calcolo è nell'else, quindi parte solo con dati corretti. Nella catena elif ogni ramo controlla solo il limite superiore. Chiedere / fare: con 72 e 1.75 l'IMC vale 23.5. Cosa cambia se scrivo quattro if separati invece degli elif? (con imc = 15 risultano vere tre condizioni: l'ultimo assegnamento vince).
Soluzione · laboratorio 1

bancomat.py

saldo: float = 1000.00

print("=== BANCOMAT ===")
print(f"Saldo attuale: {saldo:.2f} EUR")
operazione: str = input("Operazione (D=Deposito, P=Prelievo, S=Saldo): ").upper()
if operazione == "S":
    print(f"Saldo disponibile: {saldo:.2f} EUR")
elif operazione == "D" or operazione == "P":
    importo: float = float(input("Importo: "))
    if importo <= 0:
        print("Errore: l'importo deve essere positivo")
    elif operazione == "D":
        saldo = saldo + importo
        print(f"Deposito di {importo:.2f} EUR effettuato.")
        print(f"Nuovo saldo: {saldo:.2f} EUR")
    elif importo > saldo:
        print(f"Errore: saldo insufficiente ({saldo:.2f} EUR)")
    else:
        saldo = saldo - importo
        print(f"Prelievo di {importo:.2f} EUR effettuato.")
        print(f"Nuovo saldo: {saldo:.2f} EUR")
else:
    print(f"Errore: operazione '{operazione}' non riconosciuta")
  • .upper() subito dopo input(): poi basta confrontare con le maiuscole.
  • L'importo si chiede solo per D e P, quindi dentro il loro ramo.
  • Il controllo importo <= 0 va prima degli altri: senza, un prelievo di −10 aumenterebbe il saldo.
⏱ 3' · blocco «Soluzioni L01» Da dire: due livelli di if: fuori si sceglie l'operazione, dentro si controlla l'importo. L'ordine dei controlli conta. Chiedere / fare: far provare P con -10 togliendo il controllo sull'importo: il saldo diventa 1010.00.

sfida_temperatura.py

ZERO_ASSOLUTO: float = -273.15

celsius: float = float(input("Temperatura in Celsius: "))

if celsius < ZERO_ASSOLUTO:
    print("Errore: temperatura sotto lo zero assoluto (-273.15 °C)")
else:
    fahrenheit: float = celsius * 9 / 5 + 32
    if celsius <= -10:
        percezione: str = "Gelido"
    elif celsius <= 5:
        percezione = "Freddo"
    elif celsius <= 18:
        percezione = "Mite"
    elif celsius <= 30:
        percezione = "Caldo"
    else:
        percezione = "Torrido"

    print("=== REPORT TEMPERATURA ===")
    print(f"Celsius:    {celsius:.1f}°C")
    print(f"Fahrenheit: {fahrenheit:.1f}°F")
    print(f"Percezione: {percezione}")
  • Lo zero assoluto si controlla per primo; il resto del programma sta nell'else.
  • Ogni elif controlla solo il limite superiore: 18 cade in Mite perché il test è <= 18.
  • La costante ZERO_ASSOLUTO evita di scrivere −273.15 in due punti.
⏱ 3' · blocco «Soluzioni L01» Da dire: è la temperatura di prima più una catena elif come nell'IMC. I confini della tabella sono inclusi (fino a 5, fino a 18...), quindi si usa <=. Chiedere / fare: casi limite: -10 → Gelido, 5 → Freddo, 30 → Caldo, -300 → errore.

Stringhe come Struttura Dati

Sequenze immutabili di caratteri

Sequenze immutabili

Sequenza = supporta indicizzazione e slicing

Immutabile = una volta creata, non può essere modificata

testo: str = "Statistica"

print(testo[0])     # 'S'
print(testo[-1])    # 'a'
print(testo[0:4])   # 'Stat'
print(testo[::-1])  # 'acitsitatS'
print(len(testo))   # 10
print("ist" in testo)  # True

Immutabilità in pratica

Modificare un carattere è un errore:

testo: str = "Statistica"
testo[0] = "s"  # TypeError: 'str' object does not support item assignment

Per "modificare" una stringa, bisogna crearne una nuova:

testo: str = "Statistica"
testo_minuscolo: str = "s" + testo[1:]
print(testo_minuscolo)  # "statistica"
Ogni metodo delle stringhe restituisce una nuova stringa, senza modificare l'originale.

Slicing

testo[inizio:fine:passo] prende i caratteri da inizio a fine escluso.

testo: str = "Statistica"

print(testo[0:4])    # Stat      (da 0 a 3: il 4 è escluso)
print(testo[4:])     # istica    (da 4 alla fine)
print(testo[:4])     # Stat      (dall'inizio a 3)
print(testo[-3:])    # ica       (gli ultimi tre)
print(testo[::2])    # Saitc     (un carattere sì e uno no)
print(testo[::-1])   # acitsitatS
⏱ 4' · blocco «Stringhe come sequenze» Da dire: l'indice di fine è escluso, come in range(). Se manca l'inizio si parte da 0, se manca la fine si arriva in fondo. Gli indici negativi contano dalla fine. Chiedere / fare: cosa dà testo[2:5]? (ati). E testo[-1]? (a).

Scorrere una stringa

Una stringa si scorre con for come una sequenza: a ogni giro la variabile vale un carattere.

parola: str = "zucca"

for carattere in parola:
    print(carattere, end=" ")    # z u c c a
print()

for i in range(len(parola)):
    print(i, parola[i])          # 0 z, 1 u, 2 c, ...
Il secondo ciclo serve quando oltre al carattere vi serve la sua posizione.
⏱ 3' · blocco «Stringhe come sequenze» Da dire: è lo stesso for di T09; al posto di range() c'è la stringa. Questi due cicli servono domani in laboratorio. Chiedere / fare: come contereste le «t» di «statistica»? (contatore nel ciclo: 3).

Metodi Fondamentali delle Stringhe

Il toolkit per lavorare con il testo

strip(), lstrip(), rstrip()

Rimozione di spazi, tab e newline dai bordi della stringa.

dato: str = "  42.5  \n"
pulito: str = dato.strip()
print(repr(pulito))  # '42.5'

# lstrip() solo a sinistra, rstrip() solo a destra
Nella pulizia di dati importati da file, strip() è quasi sempre il primo metodo da chiamare.

replace()

Sostituisce tutte le occorrenze di una sottostringa:

testo: str = "valore: N/A"
pulito: str = testo.replace("N/A", "0")
print(pulito)  # 'valore: 0'

dati: str = "1,2,,4,,6"
dati_puliti: str = dati.replace(",,", ",0,")
print(dati_puliti)  # '1,2,0,4,0,6'

count()

Conta quante volte compare una sottostringa:

testo: str = "statistica"
print(testo.count("t"))     # 3
print(testo.count("ti"))    # 2
print(testo.count("x"))     # 0

find() e index()

testo: str = "La media campionaria"

# find() restituisce la posizione, o -1 se non trovato
pos: int = testo.find("media")
print(pos)  # 3

pos_assente: int = testo.find("varianza")
print(pos_assente)  # -1

# index() fa lo stesso, ma lancia ValueError se non trovato

startswith() e endswith()

nome_file: str = "dati_2024.csv"

print(nome_file.startswith("dati"))  # True

Utile per filtrare nomi di file, controllare formati, validare input.

Maiuscole e minuscole

testo: str = "statistica Descrittiva"

print(testo.upper())       # 'STATISTICA DESCRITTIVA'
print(testo.lower())       # 'statistica descrittiva'
print(testo.title())       # 'Statistica Descrittiva'
print(testo.capitalize())  # 'Statistica descrittiva'

Uso pratico — confronti case-insensitive:

risposta: str = "Si"
if risposta.lower() == "si":
    print("Confermato")

Formattare i numeri

media: float = 27.4567
print(f"Media: {media:.2f}")     # Media: 27.46
print(f"Media: {media:.1f}")     # Media: 27.5

quota: float = 0.0325
print(f"Quota: {quota:.1%}")     # Quota: 3.2%
print(f"Quota: {quota:.0%}")     # Quota: 3%
FormatoSignificatoEsempio
.2f2 cifre decimalif"{3.14159:.2f}" → 3.14
.1%percentuale con 1 decimale (moltiplica per 100)f"{0.0325:.1%}" → 3.2%
Il formato cambia solo la stampa: la variabile mantiene tutte le sue cifre.
⏱ 3' · blocco «Formattare i numeri» Da dire: nel corso servono solo due formati: .Nf per il numero di decimali e .N% per le percentuali. Il formato % moltiplica per 100 e aggiunge il simbolo. Chiedere / fare: cosa stampa f"{2 / 3:.1%}"? (66.7%). E f"{0.5:.0%}"? (50%).

Esercizio 1 — Contare

Data frase = "la statistica è una scienza", contate quante volte compare la lettera a. Fatelo in due modi: con un ciclo e con un metodo.
Cosa usereste?
Con il ciclo servono for, if e un contatore; con un metodo basta count(). find() dà solo la posizione della prima a, len() conta tutti i caratteri.
  1. Partire da conta = 0.
  2. Scorrere la frase un carattere alla volta con for.
  3. Se il carattere è "a", aumentare conta di 1.
  4. Controllo: frase.count("a") deve dare lo stesso numero, 5.
⏱ 3' · blocco «Esercizi in aula» Da dire: è il pattern contatore di T09 applicato a una stringa. Chiedere / fare: un minuto a coppie, poi raccogliere le proposte. Se propongono find(): frase.find("a") restituisce 1, la posizione della prima a. Chiedere cosa restituisce len(frase) (27) e perché non è la risposta.

Soluzione — Contare

frase: str = "la statistica è una scienza"

conta: int = 0
for carattere in frase:
    if carattere == "a":
        conta += 1

print(conta)               # 5
print(frase.count("a"))    # 5
⏱ 1' · blocco «Esercizi in aula» Da dire: le a sono in «la», due in «statistica», «una», «scienza»: 5. Chiedere / fare: cosa cambia con frase.count("A")? (0: il confronto distingue maiuscole e minuscole).

Esercizio 2 — Estensione

Dato nome_file = "vendite_2026.csv", stampate il nome senza estensione (vendite_2026) e l'estensione (csv). Se il nome non contiene il punto, stampate un messaggio.
Cosa usereste?
find() trova la posizione del punto, lo slicing prende le parti prima e dopo, if gestisce il caso senza punto. index() con un nome senza punto si ferma con ValueError.
  1. Cercare la posizione del punto: find(".") dà 12.
  2. Se il risultato è -1, il punto non c'è: stampare il messaggio.
  3. Altrimenti il nome va dall'inizio al punto escluso: [:punto].
  4. L'estensione parte dal carattere dopo il punto: [punto + 1:].
⏱ 3' · blocco «Esercizi in aula» Da dire: find e index trovano la stessa posizione; cambia solo il comportamento quando il punto manca (-1 contro errore). Chiedere / fare: se propongono replace(".csv", ""): funziona solo se l'estensione è già nota, con "dati.xlsx" non toglie nulla. Chiedere cosa stamperebbe nome_file[:-1] se find desse -1 e non lo controllassimo ("vendite_2026.cs": risultato sbagliato senza errore).

Soluzione — Estensione

nome_file: str = "vendite_2026.csv"

punto: int = nome_file.find(".")
if punto == -1:
    print("Il file non ha estensione")
else:
    print(nome_file[:punto])       # vendite_2026
    print(nome_file[punto + 1:])   # csv
⏱ 1' · blocco «Esercizi in aula» Da dire: il punto è in posizione 12; [:12] prende i caratteri da 0 a 11. Chiedere / fare: provare a voce con nome_file = "leggimi" (stampa il messaggio).

Esercizio 3 — Nome e iniziali

Dato dato = "  mARIO rossi  " (con due spazi all'inizio e alla fine), stampate Mario Rossi e le iniziali M.R..
Cosa usereste?
strip() toglie gli spazi ai bordi, title() sistema le maiuscole, find(" ") trova lo spazio, gli indici danno le iniziali, la f-string le compone. capitalize() darebbe Mario rossi.
  1. Togliere gli spazi ai bordi: "mARIO rossi".
  2. Prima lettera maiuscola in ogni parola: "Mario Rossi".
  3. Prima iniziale: il carattere in posizione 0.
  4. Seconda iniziale: il carattere dopo lo spazio, cioè spazio + 1.
  5. Comporre "M.R." con una f-string.
⏱ 3' · blocco «Esercizi in aula» Da dire: i metodi si possono concatenare: dato.strip().title() applica prima strip, poi title al risultato. Chiedere / fare: chiedere la differenza tra title() e capitalize() su "mARIO rossi" (Mario Rossi contro Mario rossi). upper() darebbe MARIO ROSSI.

Soluzione — Nome e iniziali

dato: str = "  mARIO rossi  "

nome: str = dato.strip().title()
spazio: int = nome.find(" ")

print(nome)                                   # Mario Rossi
print(f"{nome[0]}.{nome[spazio + 1]}.")      # M.R.
⏱ 1' · blocco «Esercizi in aula» Da dire: in "Mario Rossi" lo spazio è in posizione 5, quindi la R è in posizione 6. Chiedere / fare: cosa succede con due spazi tra nome e cognome? (nome[spazio + 1] è uno spazio: lo sistemiamo con split, che vediamo con le liste).

Esercizio 4 — CAP

Chiedete un CAP con input() e stampate se è valido. Un CAP è valido se ha 5 caratteri, tutti cifre.
Cosa usereste?
len() controlla la lunghezza, isdigit() che siano tutte cifre, and unisce le due condizioni. Con int() 00184 diventa 184 e una lettera fa fermare il programma con un errore.
  1. Leggere il CAP con input() e tenerlo come stringa.
  2. Controllare che la lunghezza sia 5.
  3. Controllare che tutti i caratteri siano cifre.
  4. Unire le due condizioni con and in un solo if.
⏱ 2' · blocco «Esercizi in aula» Da dire: il CAP si tiene come stringa: è un codice, non una quantità, e non ci si fanno calcoli. Chiedere / fare: se propongono int(): chiedere cosa diventa "00184" (184, 3 cifre) e cosa succede con "35l21" (ValueError).

Soluzione — CAP

cap: str = input("CAP: ")

if len(cap) == 5 and cap.isdigit():
    print("CAP valido")
else:
    print("CAP non valido")
⏱ 1' · blocco «Esercizi in aula» Da dire: len e isdigit bastano; l'ordine delle due condizioni non cambia il risultato. Chiedere / fare: 35121 valido, 3512 non valido, 35l21 non valido, 00184 valido.

Riepilogo

Punti chiave

  1. Una stringa è una sequenza di caratteri: si usano indici, slicing, len(), in e il ciclo for.
  2. Le stringhe sono immutabili: ogni metodo (strip(), replace(), upper(), ...) restituisce una stringa nuova.
  3. Per stampare i numeri servono due formati: .2f per i decimali e .1% per le percentuali.

Domande di verifica

  1. Cosa stampa "Statistica"[2:5]? E "Statistica"[-3:]?
  2. Cosa significa che le stringhe sono immutabili? Cosa succede con testo.upper() se non assegnate il risultato?
  3. Che differenza c'è tra find() e index() quando la sottostringa non c'è?
  4. Perché un CAP va tenuto come stringa e non come numero?
  5. Cosa stampa f"{0.1573:.1%}"?
