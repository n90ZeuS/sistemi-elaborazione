Dizionari

Coppie chiave-valore con accesso istantaneo

Cos'è un dizionario

Un dizionario è una collezione di coppie chiave-valore.

Data la chiave, il dizionario restituisce il valore corrispondente in tempo costante. 
studente: dict[str, str] = {
    "nome": "Anna",
    "cognome": "Rossi",
    "matricola": "SM00123",
    "corso": "Scienze Statistiche"
}

print(studente["nome"])       # Anna
print(studente["matricola"])  # SM00123

Sintassi: {chiave: valore, chiave: valore, ...}

Analogia: un dizionario è come un'anagrafe dove cercate per codice fiscale, non per posizione nella lista.

Creare dizionari

# Letterale (il più comune)
voti: dict[str, int] = {"analisi": 28, "informatica": 30, "statistica": 27}

# Dizionario vuoto
rubrica: dict[str, str] = {}

# Con la funzione dict() e argomenti con nome
configurazione: dict[str, int] = dict(larghezza=800, altezza=600, dpi=150)

# Da una lista di tuple (chiave, valore)
coppie: list[tuple[str, int]] = [("a", 1), ("b", 2), ("c", 3)]
da_coppie: dict[str, int] = dict(coppie)

Accesso, modifica, aggiunta, rimozione

voti: dict[str, int] = {"analisi": 28, "informatica": 30}

# Accesso
print(voti["analisi"])  # 28

# Modifica di un valore esistente
voti["analisi"] = 29

# Aggiunta di una nuova coppia
voti["statistica"] = 27

# Rimozione
del voti["informatica"]

print(voti)  # {"analisi": 29, "statistica": 27}
Attenzione: accedere a una chiave inesistente solleva un KeyError

Gestire chiavi mancanti

# Errore a runtime!
print(voti["algebra"])
# KeyError: 'algebra'
# Controllare prima
if "algebra" in voti:
    print(voti["algebra"])
else:
    print("Esame non trovato")

Vedremo tra poco un modo ancora migliore: il metodo get()

Perché O(1)? Hash table

chiave "analisi" --> hash("analisi") --> posizione 4827 --> valore 28
chiave "statistica" --> hash("statistica") --> posizione 1293 --> valore 27
  • Python calcola un hash (numero intero) dalla chiave
  • L'hash determina direttamente la posizione in memoria
  • Nessuna scansione: accesso diretto alla posizione
print(hash("analisi"))    # Un intero (es. 2837465918273...)
print(hash(42))           # 42
print(hash((1, 2, 3)))    # Un intero calcolato dalla tupla
La hash table è la struttura dati più importante in informatica pratica. È il segreto dell'efficienza dei dizionari.

Le chiavi devono essere immutabili

Se una chiave potesse cambiare, il suo hash cambierebbe e il dizionario non saprebbe più dove trovare il valore.

# OK: chiavi immutabili
d = {"ciao": 1}
d2 = {42: "risposta"}
d3 = {(0, 0): "origine"}
# ERRORE: le liste
# non sono hashable
d4 = {[1, 2]: "errore"}
# TypeError: unhashable
#   type: 'list'
Regola: stringhe, numeri e tuple possono essere chiavi. Liste e set no.

Dizionari ordinati per inserimento

Da Python 3.7+, i dizionari mantengono l'ordine di inserimento. 
ordine: dict[str, int] = {}
ordine["terzo"] = 3
ordine["primo"] = 1
ordine["secondo"] = 2

for chiave in ordine:
    print(chiave)
# Output: terzo, primo, secondo
# (ordine di inserimento, NON alfabetico)
Nelle versioni precedenti di Python l'ordine non era garantito. È un dettaglio storico che potreste trovare in materiale più datato.

Metodi principali dei dizionari

get(), keys(), values(), items(), update(), pop()

get(): accesso sicuro

Se la chiave non esiste, restituisce un valore di default invece di sollevare KeyError:

voti: dict[str, int] = {"analisi": 28, "statistica": 27}

# Restituisce None se la chiave manca
risultato: int | None = voti.get("algebra")
print(risultato)  # None

# Con un default esplicito
risultato_default: int = voti.get("algebra", 0)
print(risultato_default)  # 0

get() per conteggi

Pattern molto comune: contare occorrenze con get():

conteggi: dict[str, int] = {}
parole: list[str] = ["casa", "albero", "casa", "gatto", "albero", "casa"]

for parola in parole:
    conteggi[parola] = conteggi.get(parola, 0) + 1

print(conteggi)  # {"casa": 3, "albero": 2, "gatto": 1}
Come funziona: se la parola non esiste nel dizionario, get() restituisce 0; poi si aggiunge 1.

keys(), values(), items()

Restituiscono viste (view) sul dizionario:

esame: dict[str, int | str] = {"nome": "Statistica", "cfu": 9, "anno": 1}

print(list(esame.keys()))    # ["nome", "cfu", "anno"]
print(list(esame.values()))  # ["Statistica", 9, 1]
print(list(esame.items()))   # [("nome", "Statistica"), ("cfu", 9), ...]
Modo pythonic per iterare: 
voti: dict[str, int] = {"analisi": 28, "statistica": 27, "informatica": 30}

for esame, voto in voti.items():
    if voto >= 28:
        print(f"{esame}: ottimo ({voto})")

update() e pop()

update(): unire dizionari

base = {"analisi": 28,
        "statistica": 27}
nuovi = {"informatica": 30,
         "analisi": 29}

base.update(nuovi)
print(base)
# {"analisi": 29,
#  "statistica": 27,
#  "informatica": 30}

# Python 3.9+
unione = base | nuovi

pop(): rimuovere

voti = {"analisi": 28,
        "statistica": 27,
        "informatica": 30}

rimosso = voti.pop("informatica")
print(rimosso)  # 30

# Con default
assente = voti.pop("algebra", -1)
print(assente)  # -1

defaultdict e Counter

Strumenti specializzati dal modulo collections

defaultdict: default automatico

Se accedete a una chiave inesistente, la crea automaticamente con un valore di default:

from collections import defaultdict

# int() -> 0,  list() -> [],  str() -> ""
conteggi: defaultdict[str, int] = defaultdict(int)

parole = ["casa", "albero", "casa", "gatto", "albero", "casa"]
for parola in parole:
    conteggi[parola] += 1  # Se manca, parte da 0

print(dict(conteggi))  # {"casa": 3, "albero": 2, "gatto": 1}

defaultdict per raggruppare

from collections import defaultdict

studenti = [
    ("Rossi", "Statistica"),
    ("Bianchi", "Analisi"),
    ("Verdi", "Statistica"),
    ("Neri", "Analisi"),
    ("Gialli", "Informatica"),
]

per_corso: defaultdict[str, list[str]] = defaultdict(list)
for cognome, corso in studenti:
    per_corso[corso].append(cognome)

print(dict(per_corso))
# {"Statistica": ["Rossi", "Verdi"],
#  "Analisi": ["Bianchi", "Neri"],
#  "Informatica": ["Gialli"]}
defaultdict(list) crea una lista vuota per ogni nuova chiave.

Counter: contare occorrenze

Sottoclasse di dict specializzata nel conteggio:

from collections import Counter

parole = ["casa", "albero", "casa", "gatto", "albero", "casa"]
conteggio: Counter[str] = Counter(parole)

print(conteggio)              # Counter({"casa": 3, "albero": 2, ...})
print(conteggio["casa"])      # 3
print(conteggio["drago"])     # 0 (non solleva errore!)
print(conteggio.most_common(2))  # [("casa", 3), ("albero", 2)]

Counter: esempio statistico

from collections import Counter

risposte = [
    "molto", "poco", "abbastanza", "molto", "molto",
    "poco", "abbastanza", "molto", "per_niente", "poco"
]
frequenze: Counter[str] = Counter(risposte)

totale: int = sum(frequenze.values())
for risposta, conteggio in frequenze.most_common():
    percentuale: float = conteggio / totale * 100
    print(f"{risposta:>12}: {conteggio:>2} ({percentuale:.1f}%)")
       molto:  4 (40.0%)
        poco:  3 (30.0%)
  abbastanza:  2 (20.0%)
  per_niente:  1 (10.0%)

Set

Insiemi di elementi unici

Cos'è un set

Un set è una collezione non ordinata di elementi unici.

# Creare un set
numeri: set[int] = {1, 2, 3, 4, 5}

# I duplicati vengono eliminati automaticamente
con_duplicati: set[int] = {1, 2, 2, 3, 3, 3}
print(con_duplicati)  # {1, 2, 3}

# Creare un set da una lista (rimuove duplicati)
lista = ["roma", "milano", "roma", "napoli", "milano"]
citta_uniche: set[str] = set(lista)
print(citta_uniche)  # {"roma", "milano", "napoli"}
Attenzione: {} crea un dizionario vuoto! Per un set vuoto: set()

Set: ricerca O(1)

Come i dizionari, i set usano internamente una hash table:

grandi_numeri: set[int] = set(range(1_000_000))

# Questo è O(1) — praticamente istantaneo
print(999_999 in grandi_numeri)  # True
Set
x in mio_set
O(1) — costante
Lista
x in mia_lista
O(n) — lineare

Operazioni insiemistiche

a: set[int] = {1, 2, 3, 4, 5}
b: set[int] = {4, 5, 6, 7, 8}
OperazioneOperatoreRisultato
Unionea | b{1, 2, 3, 4, 5, 6, 7, 8}
Intersezionea & b{4, 5}
Differenzaa - b{1, 2, 3}
Diff. simmetricaa ^ b{1, 2, 3, 6, 7, 8}
Sottoinsiemea <= bFalse

Esempio: confrontare risposte

domanda_1: set[str] = {"Rossi", "Bianchi", "Verdi", "Neri", "Gialli"}
domanda_2: set[str] = {"Bianchi", "Neri", "Viola", "Rosa"}

# Chi ha risposto a entrambe?
entrambe = domanda_1 & domanda_2
print(f"Entrambe: {entrambe}")   # {"Bianchi", "Neri"}

# Chi ha risposto solo alla prima?
solo_prima = domanda_1 - domanda_2
print(f"Solo prima: {solo_prima}")  # {"Rossi", "Verdi", "Gialli"}

# Chi ha risposto ad almeno una?
almeno_una = domanda_1 | domanda_2
print(f"Almeno una: {almeno_una}")

Aggiungere e rimuovere elementi

colori: set[str] = {"rosso", "verde", "blu"}

colori.add("giallo")       # Aggiunge un elemento
colori.discard("verde")    # Rimuove (nessun errore se assente)
colori.remove("rosso")     # Rimuove (KeyError se assente)

print(colori)  # {"blu", "giallo"}
discard()
Silenzioso se l'elemento non c'è
remove()
Solleva KeyError se l'elemento non c'è

frozenset: il set immutabile

Come la tupla sta alla lista, il frozenset sta al set:

fisso: frozenset[int] = frozenset([1, 2, 3, 4])

print(3 in fisso)    # True
print(fisso | {5})   # frozenset({1, 2, 3, 4, 5}) — nuovo frozenset

# fisso.add(5)  # AttributeError!
Vantaggio: essendo immutabile, un frozenset è hashable. Potete usarlo come chiave di un dizionario o come elemento di un altro set. 
# Un set di set NON è possibile (TypeError: unhashable)
# Ma un set di frozenset sì
insiemi: set[frozenset[int]] = {frozenset([1, 2]), frozenset([3, 4])}

Mutabilità vs Immutabilità

Un tema trasversale fondamentale

Quali tipi sono mutabili?

Immutabili

int
float
str
bool
tuple
frozenset

Mutabili

list
dict
set
Conseguenza pratica: solo i tipi immutabili possono essere usati come chiavi di dizionario o elementi di set.

Immutabili: ogni "modifica" crea un nuovo oggetto

a: str = "ciao"
b: str = a        # b punta allo stesso oggetto di a
a = a + " mondo"  # a ora punta a un NUOVO oggetto
print(b)          # "ciao" — b non è cambiato
Passo 1: a ---> "ciao" <--- b
Passo 2: a ---> "ciao mondo"    b ---> "ciao"

Mutabili: attenzione agli alias!

lista_a: list[int] = [1, 2, 3]
lista_b: list[int] = lista_a   # lista_b punta allo STESSO oggetto
lista_a.append(4)               # Modifica l'oggetto
print(lista_b)                  # [1, 2, 3, 4] — anche lista_b è cambiato!
lista_a ---> [1, 2, 3, 4] <--- lista_b
Stesso oggetto in memoria! 
# Verifica con id()
print(id(lista_a) == id(lista_b))  # True — stesso oggetto!
Questo è uno dei bug più comuni per i principianti. È fondamentale capire che l'assegnazione non copia, ma crea un alias.

Come fare una vera copia

lista_a: list[int] = [1, 2, 3]

# Tre modi per creare una copia superficiale
lista_c: list[int] = lista_a.copy()
lista_d: list[int] = list(lista_a)
lista_e: list[int] = lista_a[:]

print(id(lista_a) == id(lista_c))  # False — oggetti diversi
Con una copia, le modifiche a un oggetto non influenzano l'altro.

Side effect nelle funzioni

In Python, gli argomenti sono passati per riferimento all'oggetto.

Immutabile: nessun problema

def aggiungi_dieci(n: int) -> int:
    n = n + 10  # Nuovo oggetto
    return n

valore = 5
risultato = aggiungi_dieci(valore)
print(valore)  # 5 (intatto)

Mutabile: side effect!

def aggiungi(lista, elem):
    lista.append(elem)
    # Modifica l'originale!

numeri = [1, 2, 3]
aggiungi(numeri, 4)
print(numeri)  # [1,2,3,4]

Evitare side effect indesiderati

Lavorare su una copia dentro la funzione:

def ordina_senza_modificare(lista: list[int]) -> list[int]:
    copia: list[int] = lista.copy()
    copia.sort()
    return copia

originale: list[int] = [3, 1, 4, 1, 5]
ordinata: list[int] = ordina_senza_modificare(originale)
print(originale)  # [3, 1, 4, 1, 5] — intatta
print(ordinata)   # [1, 1, 3, 4, 5]
Regola pratica: se non volete che una funzione modifichi l'oggetto passato, lavorate su una copia.

Esempio: combinare tutto

from collections import Counter

registrazioni = [
    ("Rossi", 28), ("Bianchi", 25), ("Rossi", 30),  # Rossi ha rifatto l'esame
    ("Verdi", 22), ("Bianchi", 27), ("Neri", 30),
]

# Dict: teniamo solo l'ultimo voto per ogni studente
ultimi_voti: dict[str, int] = {}
for studente, voto in registrazioni:
    ultimi_voti[studente] = voto

# Set: chi ha preso 30?
trenta: set[str] = {s for s, v in ultimi_voti.items() if v == 30}
print(trenta)  # {"Rossi", "Neri"}

# Counter: distribuzione dei voti
distribuzione: Counter[int] = Counter(ultimi_voti.values())
print(distribuzione)  # Counter({30: 2, 27: 1, 22: 1})

Complessità: O(1) vs O(n)

Come scala il vostro codice?

L'idea di Big O

O(1) — Costante

Il tempo non dipende dalla dimensione dei dati.
10 o 10 milioni di elementi: stesso tempo.

O(n) — Lineare

Il tempo cresce proporzionalmente al numero di elementi.
10x dati = 10x tempo.

Big O descrive come scala un algoritmo, ignorando costanti e dettagli.

Un esempio concreto

Verificare se un codice fiscale è presente tra 100.000:

import time

codici_lista = [f"CF{i:06d}" for i in range(100_000)]
codici_set = set(codici_lista)

# Ricerca in una lista: O(n)
inizio = time.time()
for _ in range(1000):
    _ = "CF099999" in codici_lista
tempo_lista = time.time() - inizio

# Ricerca in un set: O(1)
inizio = time.time()
for _ in range(1000):
    _ = "CF099999" in codici_set
tempo_set = time.time() - inizio

print(f"Lista: {tempo_lista:.4f}s")  # Es. 1.2345s
print(f"Set:   {tempo_set:.4f}s")    # Es. 0.0002s
La differenza è di diversi ordini di grandezza. Scegliere la struttura dati giusta è una decisione progettuale fondamentale.

Quando O(n) va bene

Se la vostra lista ha 20 elementi, la differenza tra O(1) e O(n) è trascurabile.

Big O diventa importante quando i dati crescono: centinaia, migliaia, milioni di elementi.

Regola pratica: se dovete fare ricerche ripetute su una collezione che cresce, preferite dict o set.
