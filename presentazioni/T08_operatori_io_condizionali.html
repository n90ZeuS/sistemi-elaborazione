Operatori

Calcolare con i dati

Operatori aritmetici

a: int = 17
b: int = 5

print(a + b)    # 22  — addizione
print(a - b)    # 12  — sottrazione
print(a * b)    # 85  — moltiplicazione
print(a / b)    # 3.4 — divisione vera (restituisce SEMPRE un float)
print(a // b)   # 3   — divisione intera (tronca verso il basso)
print(a % b)    # 2   — modulo (resto della divisione)
print(a ** b)   # 1419857 — potenza (17⁵)
Sette operatori aritmetici. Notare che / restituisce sempre un float, anche quando il risultato sarebbe intero (10/2 = 5.0).

Divisione: / vs //

Nota storica: in Python 2, / tra interi restituiva un intero (17 / 5 dava 3). Fonte di bug insidiosi!

/ — Divisione vera

17 / 5   # 3.4
10 / 2   # 5.0  (sempre float!)
-17 / 5  # -3.4

// — Divisione intera

17 // 5   # 3
10 // 2   # 5   (int)
-17 // 5  # -4  (tronca verso il basso)
Regola: usate / per risultati decimali, // quando volete esplicitamente la parte intera.

L'operatore modulo %

Il modulo restituisce il resto della divisione. Molto utile in pratica:

# Verificare la divisibilità
n: int = 42
print(n % 2 == 0)   # True → n è pari

# Ciclare tra valori (0, 1, 2, 0, 1, 2, ...)
for i in range(9):
    print(i % 3, end=" ")  # 0 1 2 0 1 2 0 1 2

# Estrarre l'ultima cifra
print(1234 % 10)    # 4
Il modulo è uno degli operatori meno intuitivi per chi inizia, ma diventa indispensabile. Usato tantissimo per verificare parità, ciclicità, e estrazione di cifre.

Operatori di confronto

x: int = 10
y: int = 20

print(x == y)   # False — uguaglianza (valore)
print(x != y)   # True  — diverso
print(x < y)    # True  — minore
print(x > y)    # False — maggiore
print(x <= y)   # True  — minore o uguale
print(x >= y)   # False — maggiore o uguale
Tutti gli operatori di confronto restituiscono un bool (True o False).

== vs is

a: list[int] = [1, 2, 3]
b: list[int] = [1, 2, 3]
c: list[int] = a

print(a == b)   # True  — stesso VALORE
print(a is b)   # False — oggetti DIVERSI in memoria
print(a is c)   # True  — stesso OGGETTO (c è un alias di a)
== confronta il valore:
"contengono la stessa cosa?"
is confronta l'identità:
"sono lo stesso oggetto in memoria?"

Unica eccezione idiomatica: if x is None: (non if x == None:)

Operatori logici

eta: int = 20
reddito: float = 15000.0

print(eta >= 18 and reddito < 20000)   # True — entrambe vere
print(eta < 18 or reddito > 50000)     # False — nessuna vera
print(not (eta >= 18))                 # False — negazione

Sono gli stessi AND, OR, NOT dell'algebra booleana (Lezione 2), applicati al codice.

Short-circuit evaluation

Python è "pigro": smette di valutare appena conosce il risultato.

and

Se la prima condizione è False, il risultato è False — la seconda non viene valutata.

or

Se la prima condizione è True, il risultato è True — la seconda non viene valutata.

# Garanzia di sicurezza: la divisione per zero NON viene eseguita
x: int = 0
if x != 0 and 10 / x > 2:
    print("OK")
Non è solo un'ottimizzazione — è una garanzia di sicurezza che potete sfruttare.

Operatori di appartenenza: in

vocali: str = "aeiou"
print("a" in vocali)       # True
print("b" not in vocali)   # True

numeri: list[int] = [1, 2, 3, 4, 5]
print(3 in numeri)          # True
in funziona con: stringhe, liste, tuple, set, dizionari.
Operatore potentissimo che useremo costantemente nel corso.

Precedenza degli operatori

PrioritàOperatoriEsempio
1 (massima)**2 ** 3

4==, !=, <, >, <=, >=13 > 10

risultato: bool = 3 + 5 * 2 > 10 and not False
# Equivale a: ((3 + (5 * 2)) > 10) and (not False)
# Cioè:       (13 > 10) and True → True

Usate le parentesi!

# Ambiguo: devi ricordare
# la precedenza
risultato = 3 + 5 * 2 > 10 and not False
# Chiaro: le parentesi
# esplicitano l'ordine
risultato = ((3 + (5 * 2)) > 10) and (not False)
Best practice: non affidatevi alla memorizzazione della precedenza. Usate le parentesi per rendere esplicite le vostre intenzioni.

f-string: formattazione moderna

Introdotte in Python 3.6, le f-string sono il modo più leggibile di formattare l'output:

nome: str = "Anna"
media: float = 28.6667
esami: int = 12

# Sintassi base: f"testo {espressione}"
print(f"Studentessa: {nome}")
print(f"Media: {media}")
print(f"Esami sostenuti: {esami}")

# Espressioni dentro le graffe
eta: int = 22
print(f"Il doppio è {eta * 2}")
print(f"Tra 5 anni avrà {eta + 5} anni")
Preferite le f-string a .format() e all'operatore %.

f-string: formattazione dei numeri

media: float = 28.6667

# Decimali
print(f"Media: {media:.2f}")        # 28.67 (2 decimali)
print(f"Media: {media:.1f}")        # 28.7  (1 decimale)

# Percentuali
print(f"Percentuale: {0.856:.1%}")  # 85.6%

# Allineamento
print(f"{'Nome':<15}{'Voto':>5}")   # allineato sx/dx
print(f"{'Anna':<15}{28:>5}")
print(f"{'Marco':<15}{30:>5}")

Attenzione fondamentale: input() restituisce sempre una stringa, anche se l'utente inserisce un numero. 
# ERRORE!
eta = input("Anni? ")
print(eta + 1)
# TypeError! "25" + 1
# CORRETTO
eta: int = int(input("Anni? "))
print(eta + 1)
# 26

Flusso condizionale

Una delle due strade, in base alla condizione.

I programmi reali devono prendere decisioni. L'istruzione if permette di eseguire codice solo se una condizione è vera.

if

voto: int = 25

if voto >= 18:
    print("Esame superato!")

La struttura:

  1. La parola chiave if
  2. Una condizione (espressione che produce un bool)
  3. I due punti :
  4. Il corpo (istruzioni indentate eseguite se la condizione è vera)
L'indentazione non è opzionale in Python: definisce il blocco di codice.

if / else

voto: int = 15

if voto >= 18:
    print("Esame superato!")
else:
    print("Esame non superato.")

Due strade: una sola viene percorsa. Mai entrambe.

if / elif / else

def valuta_voto(voto: int) -> str:
    """Restituisce una valutazione testuale del voto."""
    if voto >= 28:
        return "Ottimo"
    elif voto >= 24:
        return "Buono"
    elif voto >= 18:
        return "Sufficiente"
    else:
        return "Insufficiente"
elif (else if): le condizioni vengono valutate in ordine. Si esegue il blocco della prima condizione vera. Se nessuna è vera, si esegue else.

Perché elif e non if multipli?

# if multipli: OGNI condizione
# viene valutata sempre
if voto >= 28:
    print("Ottimo")
if voto >= 24:
    print("Buono")
if voto >= 18:
    print("Sufficiente")
# voto=29 → stampa TUTTE e tre!
# elif: condizioni mutuamente
# esclusive, si ferma alla prima
if voto >= 28:
    print("Ottimo")
elif voto >= 24:
    print("Buono")
elif voto >= 18:
    print("Sufficiente")
# voto=29 → stampa solo "Ottimo"
Con elif, appena una condizione è vera, le altre non vengono nemmeno valutate.

L'operatore ternario

Per condizioni semplici con assegnamento:

Forma estesa

if voto >= 18:
    esito: str = "Promosso"
else:
    esito = "Bocciato"

Forma compatta

esito: str = "Promosso" if voto >= 18 else "Bocciato"
Regola: usatelo solo quando rende il codice più leggibile, non per ogni if/else. Se la logica è complessa, preferite la forma estesa.

Condizioni composte

eta: int = 25
reddito: float = 18000.0
residente: bool = True

# AND: entrambe devono essere vere
if eta >= 18 and reddito < 20000:
    print("Ha diritto alla borsa di studio")

# OR: almeno una deve essere vera
if eta < 18 or not residente:
    print("Non può iscriversi")
Condizioni concatenate — Python le supporta nativamente: 
voto: int = 25
if 18 <= voto <= 30:  # elegante!
    print("Voto valido")
# In altri linguaggi: voto >= 18 and voto <= 30

Best practice

Scrivere condizioni in modo pythonic

Truthy e falsy

In Python, molti valori possono essere interpretati come True o False:

Falsy (valutati come False)

  • False
  • 0, 0.0
  • "" (stringa vuota)
  • [], (), {}, set()
  • None

Truthy (valutati come True)

Tutto il resto!

  • True
  • Numeri diversi da 0
  • Stringhe non vuote
  • Collezioni non vuote

Truthy e falsy in pratica

# Confronto esplicito inutile
if len(lista) == 0:
    print("Lista vuota")

if attivo == True:
    print("È attivo")

if attivo == False:
    print("Non è attivo")
# Pythonic: sfrutta truthy/falsy
if not lista:
    print("Lista vuota")

if attivo:
    print("È attivo")

if not attivo:
    print("Non è attivo")

Early return

Gestite i casi anomali all'inizio e uscite subito:

# Nesting profondo
def calcola_media(voti):
    if len(voti) > 0:
        if all(0 <= v <= 30
               for v in voti):
            return sum(voti) / len(voti)
        else:
            raise ValueError("Non validi")
    else:
        raise ValueError("Lista vuota")
# Logica piatta
def calcola_media(voti):
    if not voti:
        raise ValueError("Lista vuota")
    if not all(0 <= v <= 30
               for v in voti):
        raise ValueError("Non validi")
    return sum(voti) / len(voti)
Principio: prima i casi anomali (con uscita immediata), poi la logica principale senza indentazione extra.

Validazione dell'input

Regola d'oro: non fidatevi mai dei dati che vengono dall'esterno. 
# Validazione semplice
eta_str: str = input("Età: ")
if not eta_str.isdigit():
    print("Errore: inserisci un numero intero positivo")
else:
    eta: int = int(eta_str)
    if eta < 0 or eta > 150:
        print("Errore: età non realistica")
    else:
        print(f"Hai {eta} anni")
Strategia: verificate il tipo (è un numero?), poi il range (è nel dominio valido?), infine procedete con la logica.
