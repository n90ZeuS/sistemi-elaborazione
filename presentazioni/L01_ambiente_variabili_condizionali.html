Parte 1
Setup dell'ambiente

Verifica dell'installazione

Aprite un terminale e verificate che Python sia installato:

python3 --version
# Output atteso: Python 3.12.x (o superiore)

Verificate anche VS Code:

code --version
VS Code non si apre da terminale? Aprite VS Code, premete Cmd+Shift+P (macOS) o Ctrl+Shift+P (Windows), cercate "Shell Command: Install 'code' command in PATH" e confermate.

Il REPL di Python

Il REPL (Read-Eval-Print Loop) e l'interprete interattivo. Si avvia con:

python3

Il prompt cambia in >>>. Provate:

>>> 2 + 3
5
>>> "ciao" * 3
'ciaociaociao'
>>> type(42)
<class 'int'>
>>> exit()
Il REPL e utile per esperimenti rapidi. Per programmi veri, useremo file .py.

Parte 2
Variabili tipizzate e operatori

Variabili, type hints e type()

Create un file variabili.py:

# Dichiarazione con type hints
nome: str = "Maria"
eta: int = 21
altezza: float = 1.68
iscritta: bool = True

# Verifica dei tipi
print(f"nome     = {nome!r:>15}  tipo: {type(nome).__name__}")
print(f"eta      = {eta!r:>15}  tipo: {type(eta).__name__}")
print(f"altezza  = {altezza!r:>15}  tipo: {type(altezza).__name__}")
print(f"iscritta = {iscritta!r:>15}  tipo: {type(iscritta).__name__}")

Output e osservazioni

nome     =         'Maria'  tipo: str
eta      =              21  tipo: int
altezza  =            1.68  tipo: float
iscritta =            True  tipo: bool
!r nella f-string mostra la rappresentazione "grezza" del valore (le stringhe appaiono con le virgolette).
:>15 allinea il valore a destra in un campo di 15 caratteri.
I type hints (str, int, ecc.) non cambiano il comportamento del programma, ma documentano le vostre intenzioni.

Operatori aritmetici

Create un file operatori.py:

a: int = 17
b: int = 5

print(f"{a} + {b}  = {a + b}")     # 22
print(f"{a} - {b}  = {a - b}")     # 12
print(f"{a} * {b}  = {a * b}")     # 85
print(f"{a} / {b}  = {a / b}")     # 3.4  (divisione vera -> float)
print(f"{a} // {b} = {a // b}")    # 3    (divisione intera)
print(f"{a} % {b}  = {a % b}")     # 2    (modulo / resto)
print(f"{a} ** {b} = {a ** b}")    # 1419857 (potenza)
Attenzione: / restituisce sempre un float, anche se il risultato e intero. Per la divisione intera usate //.

Conversioni di tipo

prezzo_stringa: str = "49.99"
prezzo: float = float(prezzo_stringa)
iva: float = prezzo * 0.22
totale: float = prezzo + iva

print(f"Prezzo: {prezzo:.2f} EUR")
print(f"IVA 22%: {iva:.2f} EUR")
print(f"Totale: {totale:.2f} EUR")
Prezzo: 49.99 EUR
IVA 22%: 11.00 EUR
Totale: 60.99 EUR
:.2f formatta il numero con esattamente 2 cifre decimali.

Parte 3
Input/Output formattato

Calcolo interattivo: area del cerchio

Create un file area_cerchio.py:

import math

raggio_str: str = input("Inserisci il raggio del cerchio (in cm): ")
raggio: float = float(raggio_str)

area: float = math.pi * raggio ** 2
circonferenza: float = 2 * math.pi * raggio

print(f"\n--- Risultati ---")
print(f"Raggio:        {raggio:>10.2f} cm")
print(f"Area:          {area:>10.2f} cm²")
print(f"Circonferenza: {circonferenza:>10.2f} cm")

Output e formato :>10.2f

Inserisci il raggio del cerchio (in cm): 5

--- Risultati ---
Raggio:              5.00 cm
Area:             78.54 cm²
Circonferenza:       31.42 cm
{valore:>10.2f}
> = allinea a destra   |   10 = larghezza campo   |   .2f = 2 decimali, float
Questo formato rende l'output ordinato e leggibile, con i numeri allineati verticalmente.

Parte 4
Condizionali

Classificatore fascia ISEE

L'ISEE determina l'accesso ad agevolazioni. Scrivete un programma che classifica un reddito in fasce.

Create un file classificatore_isee.py:

# Costanti in UPPER_SNAKE_CASE (PEP 8)
SOGLIA_1: float = 6_000.00
SOGLIA_2: float = 15_000.00
SOGLIA_3: float = 25_000.00
SOGLIA_4: float = 40_000.00

reddito_str: str = input("Inserisci il reddito ISEE (in euro): ")
reddito: float = float(reddito_str)
L'underscore nelle costanti numeriche (6_000.00) migliora la leggibilita senza cambiare il valore.

Classificatore ISEE: catena if/elif/else

if reddito < 0:
    print("Errore: il reddito non puo essere negativo.")
elif reddito <= SOGLIA_1:
    fascia: str = "Fascia 1 — Esenzione totale"
    aliquota: float = 0.0
elif reddito <= SOGLIA_2:
    fascia = "Fascia 2 — Agevolazione alta"
    aliquota = 0.05
elif reddito <= SOGLIA_3:
    fascia = "Fascia 3 — Agevolazione media"
    aliquota = 0.10
elif reddito <= SOGLIA_4:
    fascia = "Fascia 4 — Agevolazione ridotta"
    aliquota = 0.15
else:
    fascia = "Fascia 5 — Nessuna agevolazione"
    aliquota = 0.22

Classificatore ISEE: output formattato

if reddito >= 0:
    contributo: float = reddito * aliquota
    print(f"\n--- Risultato ---")
    print(f"Reddito ISEE:  {reddito:>12,.2f} EUR")
    print(f"Classificazione: {fascia}")
    print(f"Aliquota:      {aliquota:>12.0%}")
    print(f"Contributo:    {contributo:>12,.2f} EUR")

Esecuzione con reddito 18500:

--- Risultato ---
Reddito ISEE:    18,500.00 EUR
Classificazione: Fascia 3 — Agevolazione media
Aliquota:              10%
Contributo:      1,850.00 EUR
:,.2f → separatore migliaia + 2 decimali
:.0% → valore come percentuale (0.10 → 10%)

Calcolatrice interattiva

Create un file calcolatrice.py:

print("=== CALCOLATRICE ===")
print("Operazioni: +  -  *  /  //  %  **")
print()

primo_str: str = input("Primo numero: ")
primo: float = float(primo_str)

operazione: str = input("Operazione: ")

secondo_str: str = input("Secondo numero: ")
secondo: float = float(secondo_str)

errore: bool = False
risultato: float = 0.0

Calcolatrice: logica e validazione

if operazione == "+":
    risultato = primo + secondo
elif operazione == "-":
    risultato = primo - secondo
elif operazione == "*":
    risultato = primo * secondo
elif operazione == "/":
    if secondo == 0:
        print("Errore: divisione per zero!")
        errore = True
    else:
        risultato = primo / secondo
elif operazione == "**":
    risultato = primo ** secondo
else:
    print(f"Errore: operazione '{operazione}' non riconosciuta.")
    errore = True

if not errore:
    print(f"\n{primo} {operazione} {secondo} = {risultato:.4f}")

Calcolatrice: casi di test

Provate questi casi e verificate i risultati:

InputRisultato atteso
10 / 33.3333 (verifica decimali)
10 / 0Messaggio di errore: divisione per zero
2 ** 101024.0000 (potenza)
17 % 52.0000 (modulo)
10 @ 3Messaggio di errore: operazione non riconosciuta
Perche controlliamo secondo == 0 solo per /, // e %? Perche la divisione per zero genera un errore a runtime, mentre addizione, sottrazione e moltiplicazione funzionano con qualsiasi valore.
