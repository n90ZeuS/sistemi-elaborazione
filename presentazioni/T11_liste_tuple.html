Liste

Sequenze ordinate e mutabili

Cosa sono le liste

Una lista e una sequenza ordinata e mutabile di elementi.

  • Ordinata — ogni elemento ha una posizione (indice)
  • Mutabile — si possono aggiungere, rimuovere e modificare elementi
temperature: list[float] = [18.5, 21.3, 19.7, 22.1, 20.4]
nomi: list[str] = ["Anna", "Marco", "Luca"]
mista: list[int | str] = [1, "due", 3]  # sconsigliato
vuota: list[float] = []
Nella pratica statistica si lavora quasi sempre con liste omogenee — tutti float, tutti int, tutti str.
Le liste possono contenere qualsiasi tipo, anche misto, ma per l'analisi dati si usano liste omogenee. I type hint lo riflettono.

Indicizzazione

Ogni elemento ha un indice che ne identifica la posizione. Gli indici partono da 0:

voti: list[int] = [28, 30, 25, 27, 22]
#                   0   1   2   3   4

primo: int = voti[0]    # 28
secondo: int = voti[1]  # 30
ultimo: int = voti[4]   # 22
indice:   0    1    2    3    4
valore: [ 28 | 30 | 25 | 27 | 22 ]

Perche si parte da 0?

Dijkstra e l'intervallo semiaperto

Per rappresentare N elementi consecutivi, la convenzione 0 <= i < N ha due vantaggi:

  • La differenza tra gli estremi da il numero di elementi: N - 0 = N
  • Due intervalli adiacenti si concatenano senza buchi: [0, 5) + [5, 10) = [0, 10)
Ragione pratica: l'indice e un offset (spiazzamento) rispetto all'inizio della sequenza in memoria. Il primo elemento ha offset 0 perche e all'inizio.

Consiglio: pensate agli indici come "quanti elementi devo saltare per arrivare a quello che voglio".

Indici negativi

Gli indici negativi contano dalla fine della lista:

voti: list[int] = [28, 30, 25, 27, 22]

ultimo: int = voti[-1]       # 22
penultimo: int = voti[-2]    # 27
primo: int = voti[-len(voti)]  # 28 (equivale a voti[0])
indice pos.:   0    1    2    3    4
indice neg.: -5   -4   -3   -2   -1
valore:      [ 28 | 30 | 25 | 27 | 22 ]
Un indice fuori range genera IndexError:
voti[10] e voti[-10] sollevano entrambi un errore.

Slicing

Estrarre sottoliste con lista[start:stop:step]

Slicing: sintassi

dati: list[int] = [10, 20, 30, 40, 50, 60, 70, 80]
#                   0   1   2   3   4   5   6   7

dati[2:5]      # [30, 40, 50]  — da indice 2 a 4 (stop escluso!)
dati[:3]       # [10, 20, 30]  — dall'inizio a indice 2
dati[5:]       # [60, 70, 80]  — da indice 5 alla fine
dati[:]        # copia completa della lista
Regola: stop e sempre escluso, coerentemente con range() e la convenzione dell'intervallo semiaperto.

Slicing: step e inversione

dati: list[int] = [10, 20, 30, 40, 50, 60, 70, 80]

dati[::2]      # [10, 30, 50, 70]  — un elemento ogni due
dati[1::2]     # [20, 40, 60, 80]  — posizioni dispari
dati[::-1]     # [80, 70, 60, 50, 40, 30, 20, 10]  — invertita
OmissioneValore predefinito
start omesso0 (inizio)
stop omessolen(lista) (fine)
step omesso1

Slicing: niente IndexError

A differenza dell'indicizzazione, lo slicing non solleva mai IndexError:

dati: list[int] = [10, 20, 30]
dati[1:100]   # [20, 30]  — nessun errore, "taglia" silenziosamente
dati[100:200] # []         — lista vuota
dati[10]  # IndexError!
dati[10:20]  # [] (nessun errore)

Operazioni e metodi

Lavorare con le liste

Concatenazione e ripetizione

a: list[int] = [1, 2, 3]
b: list[int] = [4, 5, 6]

c: list[int] = a + b        # [1, 2, 3, 4, 5, 6] — concatenazione
d: list[int] = a * 3        # [1, 2, 3, 1, 2, 3, 1, 2, 3] — ripetizione

Appartenenza

30 in voti      # True
18 not in voti  # True

Lunghezza

len(voti)       # 4
Concatenazione e ripetizione creano nuove liste; le originali restano invariate.

Aggiungere elementi

voti: list[int] = [28, 30, 25]

voti.append(27)          # [28, 30, 25, 27] — aggiunge in fondo
voti.insert(1, 29)       # [28, 29, 30, 25, 27] — inserisce alla posizione 1
voti.extend([22, 24])    # [28, 29, 30, 25, 27, 22, 24] — aggiunge piu elementi
MetodoCosa fa
append(x)Aggiunge un elemento in coda
insert(i, x)Inserisce x alla posizione i
extend(seq)Aggiunge tutti gli elementi di una sequenza (equivale a +=)

append() vs extend()

a: list[int] = [1, 2, 3]
a.append([4, 5])
# [1, 2, 3, [4, 5]]
# Ha aggiunto UNA lista
# come elemento!
b: list[int] = [1, 2, 3]
b.extend([4, 5])
# [1, 2, 3, 4, 5]
# Ha aggiunto DUE
# elementi separati
append() aggiunge l'oggetto intero come singolo elemento. extend() itera sulla sequenza e aggiunge ogni elemento.

Rimuovere elementi

voti: list[int] = [28, 30, 25, 27, 30]

voti.remove(30)     # [28, 25, 27, 30] — rimuove la PRIMA occorrenza
ultimo: int = voti.pop()     # ultimo = 30, voti = [28, 25, 27]
secondo: int = voti.pop(1)   # secondo = 25, voti = [28, 27]
MetodoCosa faSe non trova?
remove(x)Rimuove la prima occorrenza di xValueError
pop()Rimuove e restituisce l'ultimo elementoIndexError
pop(i)Rimuove e restituisce l'elemento all'indice iIndexError

Ordinare e invertire

voti: list[int] = [28, 30, 25, 27, 22]

voti.sort()              # [22, 25, 27, 28, 30] — ordina IN PLACE
voti.sort(reverse=True)  # [30, 28, 27, 25, 22] — ordine decrescente
voti.reverse()           # [22, 25, 27, 28, 30] — inverte l'ordine
Attenzione: sort() e reverse() modificano la lista in place e restituiscono None.
Non scrivete voti = voti.sort() — perdereste la lista e otterreste None!

Alternativa: sorted()

voti_ordinati: list[int] = sorted(voti)  # crea una NUOVA lista, voti resta invariata

Cercare e contare

voti: list[int] = [28, 30, 25, 27, 30]

voti.index(30)    # 1 — posizione della PRIMA occorrenza
voti.count(30)    # 2 — quante volte appare 30
MetodoRestituisceSe non trova?
index(x)Posizione della prima occorrenzaValueError
count(x)Numero di occorrenze0 (nessun errore)

Riferimenti e copie

CONCETTO CRUCIALE

L'assegnamento crea un alias

Quando scrivete b = a con una lista, non state creando una copia. State creando un alias: un secondo nome per lo stesso oggetto.

a: list[int] = [1, 2, 3]
b: list[int] = a           # b e un ALIAS di a, non una copia

b.append(4)
print(a)  # [1, 2, 3, 4] — SORPRESA! Anche a e cambiata!
Variabile      Memoria
┌───┐         ┌───────────┐
│ a │────────>│ [1, 2, 3] │
└───┘   ┌──> │           │
┌───┐   │    └───────────┘
│ b │───┘
└───┘

Verificare con id() e is

a: list[int] = [1, 2, 3]
b: list[int] = a

print(id(a))       # es. 140234567890
print(id(b))       # 140234567890 — stesso indirizzo!
print(a is b)      # True — stesso oggetto
== confronta i valori
(contengono gli stessi dati?)
is confronta le identita
(sono lo stesso oggetto in memoria?)

Shallow copy: copiare il primo livello

Per creare una vera copia, tre opzioni equivalenti:

a: list[int] = [1, 2, 3]

b: list[int] = a.copy()    # metodo copy()
c: list[int] = a[:]        # slicing completo
d: list[int] = list(a)     # costruttore list()
b.append(4)
print(a)  # [1, 2, 3] — a e rimasta invariata
print(b)  # [1, 2, 3, 4]
print(a is b)  # False — oggetti diversi
┌───┐     ┌───────────┐
│ a │───>│ [1, 2, 3] │
└───┘     └───────────┘
┌───┐     ┌───────────┐
│ b │───>│ [1, 2, 3] │  (copia indipendente)
└───┘     └───────────┘

Deep copy: strutture annidate

La copy() e una shallow copy: copia i riferimenti, non gli oggetti interni.

matrice: list[list[int]] = [[1, 2], [3, 4], [5, 6]]
copia: list[list[int]] = matrice.copy()  # shallow copy

copia[0][0] = 99
print(matrice)  # [[99, 2], [3, 4], [5, 6]] — MODIFICATA!
La shallow copy ha creato una nuova lista esterna, ma le liste interne sono ancora condivise.

La soluzione: copy.deepcopy()

import copy

matrice: list[list[int]] = [[1, 2], [3, 4], [5, 6]]
copia_profonda: list[list[int]] = copy.deepcopy(matrice)

copia_profonda[0][0] = 99
print(matrice)  # [[1, 2], [3, 4], [5, 6]] — intatta!
Regola pratica:
  • Lista di tipi immutabili (int, float, str, tuple) → basta copy()
  • Lista di oggetti mutabili (altre liste, dizionari) → serve deepcopy()

Perche conta per la statistica

import copy

dati_originali: list[list[float]] = [
    [1.2, 3.4, 5.6],
    [7.8, 9.0, 1.2],
]

# SBAGLIATO: alias — modifica anche dati_originali
dati_lavoro = dati_originali
dati_lavoro[0][0] = 0.0  # dati_originali[0][0] ora vale 0.0!

# ANCORA SBAGLIATO: shallow copy con liste annidate
dati_lavoro = dati_originali.copy()
dati_lavoro[0][0] = 0.0  # dati_originali[0][0] ancora modificato!

# CORRETTO: deep copy
dati_lavoro = copy.deepcopy(dati_originali)
dati_lavoro[0][0] = 0.0  # dati_originali resta intatta
Esempio pratico: volete "provare" una trasformazione senza alterare i dati originali. Se non copiate correttamente, corrompete il dataset.

Tuple

Sequenze ordinate e immutabili

Cosa sono le tuple

Simili alle liste, ma immutabili: una volta create, non si possono modificare.

coordinate: tuple[float, float] = (45.4642, 9.1900)  # Milano
giorni: tuple[str, ...] = ("lun", "mar", "mer", "gio", "ven", "sab", "dom")
singolo: tuple[int] = (42,)   # la virgola e necessaria!
vuota: tuple[()] = ()
Indicizzazione e slicing funzionano come per le liste.
La modifica fallisce:
coordinate[0] = 41.9
TypeError!

Type hint per le tuple

Lunghezza fissa

# Esattamente 2 float
punto: tuple[float, float]

# Esattamente 3 elementi
record: tuple[str, int, float]

Lunghezza variabile

# Numero arbitrario di str
giorni: tuple[str, ...]

# Numero arbitrario di int
valori: tuple[int, ...]
La differenza riflette l'uso: le tuple a lunghezza fissa rappresentano record (ogni posizione ha un significato diverso), quelle a lunghezza variabile rappresentano sequenze immutabili.

Perche esistono le tuple?

  1. Garanzia di immutabilita
    Se passate una tupla a una funzione, avete la certezza che non verra modificata.
  2. Hashabilita
    Le tuple possono essere usate come chiavi di dizionario o elementi di set. Le liste no.
  3. Efficienza
    Occupano meno memoria e sono piu veloci da creare e accedere.

Tuple come chiavi di dizionario

# Le tuple POSSONO
# essere chiavi
posizioni: dict[tuple[int, int], str] = {
    (0, 0): "origine",
    (1, 0): "destra",
    (0, 1): "sopra",
}
# Le liste NO
posizioni = {
    [0, 0]: "origine",
}
# TypeError:
# unhashable type: 'list'
Fondamentale per contare combinazioni, creare tabelle di contingenza, o usare coordinate come chiavi.

Unpacking

Assegnamento multiplo

Unpacking: sintassi

L'unpacking (spacchettamento) assegna gli elementi di una tupla o lista a variabili separate:

coordinate: tuple[float, float] = (45.4642, 9.1900)
lat, lon = coordinate  # lat = 45.4642, lon = 9.1900

# Funziona anche con le liste
valori: list[int] = [10, 20, 30]
a, b, c = valori  # a = 10, b = 20, c = 30
Il numero di variabili a sinistra deve corrispondere al numero di elementi a destra, altrimenti si ottiene ValueError.

Return multipli dalle funzioni

def statistiche_base(valori: list[float]) -> tuple[float, float, float]:
    """Restituisce media, minimo e massimo."""
    n: int = len(valori)
    media: float = sum(valori) / n
    minimo: float = min(valori)
    massimo: float = max(valori)
    return media, minimo, massimo  # crea automaticamente una tupla

# Unpacking del risultato
dati: list[float] = [23.5, 21.0, 25.3, 19.8, 22.1]
media, minimo, massimo = statistiche_base(dati)
print(f"Media: {media:.1f}, Range: [{minimo}, {massimo}]")
# Media: 22.3, Range: [19.8, 25.3]
return media, minimo, massimo crea implicitamente la tupla (media, minimo, massimo). Le parentesi sono opzionali.

Scambio di variabili

L'unpacking rende elegante lo scambio di due variabili:

In C

temp = a
a = b
b = temp

In Python

a, b = b, a

Python crea la tupla (b, a) a destra, poi la spacchetta nelle variabili a sinistra.

Named tuple

Quando le tuple hanno molti elementi, ricordare le posizioni diventa difficile. Le named tuple aggiungono nomi ai campi:

from collections import namedtuple

Studente = namedtuple("Studente", ["nome", "matricola", "media"])
s: Studente = Studente(nome="Anna Rossi", matricola=123456, media=27.5)

# Accesso per nome (piu leggibile)
print(s.nome)      # Anna Rossi
print(s.media)     # 27.5

# Accesso per indice (ancora possibile)
print(s[0])        # Anna Rossi

# Immutabile come una tupla normale
# s.media = 28.0   # AttributeError!

Versione moderna: typing.NamedTuple

from typing import NamedTuple

class Osservazione(NamedTuple):
    valore: float
    unita: str
    timestamp: str

o: Osservazione = Osservazione(valore=23.5, unita="°C", timestamp="2025-01-15")
print(o.valore)  # 23.5
Le named tuple sono un ponte tra le tuple e le classi: offrono campi con nome mantenendo immutabilita ed efficienza.
Le approfondiremo con classi e oggetti. Per ora basta sapere che esistono e sono utili quando una tupla ha piu di 2-3 elementi.

Applicazioni statistiche

Liste e tuple al lavoro

Campione statistico come lista

campione: list[float] = [23.5, 21.0, 25.3, 19.8, 22.1, 24.7, 20.5]

n: int = len(campione)
media: float = sum(campione) / n

# Varianza campionaria (con n-1 al denominatore)
somma_scarti_quadrati: float = sum((x - media) ** 2 for x in campione)
varianza: float = somma_scarti_quadrati / (n - 1)

print(f"n = {n}")
print(f"Media = {media:.2f}")
print(f"Varianza campionaria = {varianza:.2f}")
La struttura dati piu naturale per un campione statistico e una lista di numeri. Notare l'uso della generator expression per la somma degli scarti.

Calcolo della mediana

# Ordinamento per calcolare la mediana
campione_ordinato: list[float] = sorted(campione)  # NON sort()!

if n % 2 == 1:
    mediana: float = campione_ordinato[n // 2]
else:
    mediana = (campione_ordinato[n // 2 - 1] + campione_ordinato[n // 2]) / 2
Buona pratica: usare sorted() (nuova lista) anziche sort() (modifica in place) per preservare l'ordine originale dei dati.

Misurazioni con NamedTuple

from typing import NamedTuple

class Misurazione(NamedTuple):
    temperatura: float
    umidita: float
    ora: str

rilevamenti: list[Misurazione] = [
    Misurazione(18.5, 65.0, "08:00"),
    Misurazione(22.3, 55.0, "12:00"),
    Misurazione(25.1, 48.0, "15:00"),
    Misurazione(20.7, 62.0, "18:00"),
]

# Estrarre solo le temperature
temperature: list[float] = [m.temperatura for m in rilevamenti]
media_temp: float = sum(temperature) / len(temperature)

# Trovare il rilevamento con temperatura massima
piu_caldo: Misurazione = max(rilevamenti, key=lambda m: m.temperatura)
print(f"Picco: {piu_caldo.temperatura}°C alle {piu_caldo.ora}")

Distribuzione di frequenze

def distribuzione_frequenze(dati: list[int]) -> list[tuple[int, int]]:
    """Restituisce coppie (valore, frequenza) ordinate per valore."""
    valori_unici: list[int] = sorted(set(dati))
    frequenze: list[tuple[int, int]] = []
    for valore in valori_unici:
        freq: int = dati.count(valore)
        frequenze.append((valore, freq))
    return frequenze

voti_esame: list[int] = [25, 28, 30, 28, 27, 25, 30, 30, 28, 22, 25, 27]
for voto, freq in distribuzione_frequenze(voti_esame):
    print(f"Voto {voto}: {'█' * freq} ({freq})")
Notate l'uso combinato di set(), sorted(), count(), tuple come coppia (valore, frequenza), e unpacking nel ciclo for.
