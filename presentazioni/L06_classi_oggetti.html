Esercizio Guidato 1

Punto2D: coordinate, distanza, __str__

Punto2D — Definizione della classe

import math

class Punto2D:
    """Rappresenta un punto nel piano cartesiano."""

    def __init__(self, x: float, y: float) -> None:
        self.x: float = x
        self.y: float = y

    def distanza_da(self, altro: "Punto2D") -> float:
        dx: float = self.x - altro.x
        dy: float = self.y - altro.y
        return math.sqrt(dx ** 2 + dy ** 2)

    def distanza_da_origine(self) -> float:
        return self.distanza_da(Punto2D(0.0, 0.0))

    def __str__(self) -> str:
        return f"({self.x}, {self.y})"
Osservazione: distanza_da_origine riusa distanza_da — un metodo puo' chiamare altri metodi dello stesso oggetto tramite self.

Punto2D — Test e output

p1: Punto2D = Punto2D(3.0, 4.0)
p2: Punto2D = Punto2D(0.0, 0.0)

print(f"Punto 1: {p1}")             # Usa __str__
print(f"Punto 2: {p2}")
print(f"Distanza p1-p2: {p1.distanza_da(p2):.2f}")
print(f"Distanza p1 dall'origine: {p1.distanza_da_origine():.2f}")

Output atteso:

Punto 1: (3.0, 4.0)
Punto 2: (0.0, 0.0)
Distanza p1-p2: 5.00
Distanza p1 dall'origine: 5.00

Concetti chiave

Concetto Spiegazione
__init__ Il costruttore: viene chiamato quando si scrive Punto2D(3.0, 4.0)
self Riferimento all'oggetto corrente: ogni metodo lo riceve come primo parametro
__str__ Invocato da print() e dalle f-string per una rappresentazione leggibile

Punto2D — Aggiungere __repr__

def __repr__(self) -> str:
    """Rappresentazione tecnica: ricrea l'oggetto."""
    return f"Punto2D({self.x}, {self.y})"

__str__ — per gli umani

print(p1)
# (3.0, 4.0)

__repr__ — per i programmatori

print(repr(p1))
# Punto2D(3.0, 4.0)
Attenzione: quando si stampa una lista di oggetti, Python usa __repr__ per ogni elemento, non __str__.

Esercizio Guidato 2

Studente: validazione dei dati

Studente — Costruttore e validazione

class Studente:
    """Rappresenta uno studente universitario con i suoi voti."""

    def __init__(self, nome: str, cognome: str, matricola: str) -> None:
        if not nome.strip():
            raise ValueError("Il nome non puo' essere vuoto")
        if not cognome.strip():
            raise ValueError("Il cognome non puo' essere vuoto")
        if not matricola.strip():
            raise ValueError("La matricola non puo' essere vuota")

        self.nome: str = nome.strip()
        self.cognome: str = cognome.strip()
        self.matricola: str = matricola.strip()
        self.voti: list[int] = []
Incapsulamento: la validazione nel costruttore garantisce che un oggetto Studente sia sempre in uno stato coerente fin dalla creazione.

Studente — aggiungi_voto

def aggiungi_voto(self, voto: int) -> None:
    if not isinstance(voto, int):
        raise TypeError(
            f"Il voto deve essere un intero, ricevuto {type(voto).__name__}"
        )
    if voto < 18 or voto > 30:
        raise ValueError(
            f"Il voto deve essere tra 18 e 30, ricevuto {voto}"
        )
    self.voti.append(voto)

def media(self) -> float:
    if not self.voti:
        raise ValueError(
            f"Nessun voto registrato per {self.nome} {self.cognome}"
        )
    return sum(self.voti) / len(self.voti)

def numero_esami(self) -> int:
    return len(self.voti)

Studente — __str__ e test

def __str__(self) -> str:
    n_esami: int = self.numero_esami()
    if n_esami > 0:
        return (f"{self.nome} {self.cognome} ({self.matricola}) "
                f"- {n_esami} esami, media: {self.media():.2f}")
    return f"{self.nome} {self.cognome} ({self.matricola}) - nessun esame"
s = Studente("Anna", "Rossi", "MAT001")
print(s)                 # Anna Rossi (MAT001) - nessun esame
s.aggiungi_voto(28)
s.aggiungi_voto(25)
s.aggiungi_voto(30)
print(s)                 # Anna Rossi (MAT001) - 3 esami, media: 27.67

Studente — La validazione in azione

try:
    s.aggiungi_voto(15)        # Troppo basso
except ValueError as e:
    print(f"Errore catturato: {e}")

try:
    s.aggiungi_voto(25.5)      # Non intero
except TypeError as e:
    print(f"Errore catturato: {e}")

Output:

Errore catturato: Il voto deve essere tra 18 e 30, ricevuto 15
Errore catturato: Il voto deve essere un intero, ricevuto float
Punto chiave: la classe protegge i propri dati. Non e' possibile inserire un voto invalido. Questa e' la potenza dell'incapsulamento.

Esercizio Guidato 3

__repr__, __eq__, __lt__

Studente — __repr__ e __eq__

def __repr__(self) -> str:
    return f"Studente('{self.nome}', '{self.cognome}', '{self.matricola}')"

def __eq__(self, altro: object) -> bool:
    """Due studenti sono uguali se hanno la stessa matricola."""
    if not isinstance(altro, Studente):
        return NotImplemented
    return self.matricola == altro.matricola
s1 = Studente("Anna", "Rossi", "MAT001")
s3 = Studente("Anna", "Rossi", "MAT001")   # Stessa matricola
s2 = Studente("Marco", "Bianchi", "MAT002")

print(repr(s1))          # Studente('Anna', 'Rossi', 'MAT001')
print(f"s1 == s3? {s1 == s3}")   # True  (stessa matricola)
print(f"s1 == s2? {s1 == s2}")   # False
Perche' NotImplemented? Restituire NotImplemented (e non False) permette a Python di provare il confronto nell'altro senso.

Studente — __lt__ e ordinamento

def __lt__(self, altro: "Studente") -> bool:
    """Ordinamento per cognome, poi per nome."""
    if not isinstance(altro, Studente):
        return NotImplemented
    if self.cognome == altro.cognome:
        return self.nome < altro.nome
    return self.cognome < altro.cognome
studenti = [s1, s2, s4]   # Rossi, Bianchi, Bianchi
ordinati = sorted(studenti)
for s in ordinati:
    print(f"  {s}")

Output:

  Lucia Bianchi (MAT004) - nessun esame
  Marco Bianchi (MAT002) - nessun esame
  Anna Rossi (MAT001) - nessun esame
__lt__ e' sufficiente per far funzionare sorted(): Python usa internamente solo < per l'ordinamento.

Esercizio Guidato 4

sorted() con criteri diversi

Ordinamento con key

classe = crea_classe_esempio()

# Ordinamento predefinito: usa __lt__ (cognome, nome)
stampa_classifica(sorted(classe), "Ordine alfabetico")

# Ordinamento per media (decrescente)
per_media = sorted(classe, key=lambda s: s.media(), reverse=True)
stampa_classifica(per_media, "Classifica per media")

# Ordinamento per numero di esami
per_esami = sorted(classe, key=lambda s: s.numero_esami())

# Ordinamento per matricola
per_matricola = sorted(classe, key=lambda s: s.matricola)
Punto chiave: sorted() usa __lt__ come criterio predefinito, ma il parametro key permette di ordinare per qualsiasi attributo o calcolo.

Riepilogo metodi speciali

Metodo Quando viene chiamato Esempio
__init__ Creazione dell'oggetto Studente("Anna", "Rossi", "MAT001")
__str__ print(), f-string print(s)
__repr__ Debug, interprete, liste repr(s), print([s1, s2])
__eq__ Operatore == s1 == s2
__lt__ Operatore <, sorted() s1 < s2, sorted(lista)

Sfida finale — Classe Dataset Avanzato

Un mini-Pandas: caricare dati da CSV, filtrarli, raggrupparli, calcolare statistiche.

Metodi richiesti

  • carica_da_csv() — @staticmethod
  • n_righe(), n_colonne()
  • colonna(nome)
  • colonna_numerica(nome)
  • filtra(colonna, valore)
  • raggruppa(colonna)
  • statistiche(colonna)
  • salva_csv()

Suggerimenti

  • Dati interni: list[dict[str, str]]
  • filtra e raggruppa restituiscono nuovi Dataset
  • Non modificare l'originale

Dataset — Esempio d'uso atteso

from pathlib import Path

# Caricamento
ds = Dataset.carica_da_csv(Path("vendite.csv"), delimiter=";")
print(f"Dataset: {ds.n_righe()} righe, {ds.n_colonne()} colonne")

# Filtraggio
roma = ds.filtra("citta", "Roma")
print(f"Vendite a Roma: {roma.n_righe()} righe")

# Raggruppamento e statistiche
per_citta = ds.raggruppa("citta")
for citta, sottoinsieme in per_citta.items():
    stats = sottoinsieme.statistiche("importo")
    print(f"{citta}: media={stats['media']:.2f}, "
          f"totale={stats['somma']:.2f}")

# Salvataggio
roma.salva_csv(Path("output") / "vendite_roma.csv", delimiter=";")
