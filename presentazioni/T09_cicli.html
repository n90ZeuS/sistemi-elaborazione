Questa lezione completa i tre pilastri della programmazione imperativa: sequenza, selezione (condizionali) e iterazione (cicli).

Perché i cicli?

Abbiamo variabili, operatori e condizionali. Manca un ingrediente fondamentale: la ripetizione.

Gran parte del lavoro in statistica consiste nel fare la stessa operazione su molti dati: calcolare la media di mille osservazioni, cercare un valore anomalo, applicare una trasformazione a ogni riga.

I cicli permettono di ripetere un blocco di codice senza doverlo riscrivere.

Variabili + Condizioni + Cicli = i tre pilastri della programmazione imperativa.
Tutto il resto è costruito su questi.

Il ciclo for

Iterare sugli elementi di una sequenza

Il ciclo for: sintassi base

Il for scorre gli elementi di una sequenza, uno alla volta:

voti: list[int] = [28, 30, 25, 27, 22]

for voto in voti:
    print(f"Voto: {voto}")
lista: [28, 30, 25, 27, 22]
         ^
     voto = 28 → esegui blocco
     voto = 30 → esegui blocco
     voto = 25 → esegui blocco
         ... fino alla fine
La variabile voto assume il valore dell'elemento successivo ad ogni iterazione. Quando gli elementi finiscono, il ciclo termina.

range(): generare sequenze

# range(stop): da 0 a stop-1
for i in range(5):
    print(i)  # 0, 1, 2, 3, 4

# range(start, stop): da start a stop-1
for i in range(1, 6):
    print(i)  # 1, 2, 3, 4, 5

# range(start, stop, step): con passo
for i in range(0, 10, 2):
    print(i)  # 0, 2, 4, 6, 8
range() genera numeri pigramente (lazy evaluation), non crea una lista in memoria.

range(): contare all'indietro

# Contare all'indietro
for i in range(10, 0, -1):
    print(i)  # 10, 9, 8, ..., 1
FormaParametriRisultato
range(5)solo stop0, 1, 2, 3, 4
range(1, 6)start, stop1, 2, 3, 4, 5
range(0, 10, 2)start, stop, step0, 2, 4, 6, 8
range(10, 0, -1)step negativo10, 9, 8, ..., 1

Perché stop è escluso?

Intervallo semiaperto: [start, stop)

Coerenza con indice 0

range(n) produce esattamente n elementi (da 0 a n-1), come gli indici di una lista di lunghezza n.

Intervalli concatenabili

range(0, 5) + range(5, 10) = range(0, 10)
Nessuna sovrapposizione.

Sembra innaturale all'inizio, ma diventa rapidamente intuitivo.

enumerate(): indice e valore

Spesso serve sia l'indice che il valore.

# Anti-pattern C-style
nomi = ["Anna", "Marco", "Luca"]
for i in range(len(nomi)):
    print(f"{i}: {nomi[i]}")
# Modo pythonic
nomi = ["Anna", "Marco", "Luca"]
for i, nome in enumerate(nomi):
    print(f"{i}: {nome}")
Si può specificare un indice iniziale: enumerate(nomi, start=1)

zip(): iterare in parallelo

Iterare su più sequenze contemporaneamente:

nomi: list[str] = ["Anna", "Marco", "Luca"]
voti: list[int] = [28, 30, 25]

for nome, voto in zip(nomi, voti):
    print(f"{nome}: {voto}")
# Anna: 28
# Marco: 30
# Luca: 25
Attenzione: zip() si ferma alla sequenza più corta. Per non perdere dati con lunghezze diverse, usate itertools.zip_longest.
zip prende il nome dalla cerniera: unisce due sequenze elemento per elemento.

Il ciclo while

Ripetere finché una condizione è vera

while: sintassi base

Si usa quando non si sa in anticipo quante iterazioni servono:

risposta: str = ""
while risposta != "esci":
    risposta = input("Inserisci un comando (o 'esci'): ")
    print(f"Hai scritto: {risposta}")
condizione vera? → Sì → esegui blocco → torna a controllare
                 ↓ No
              esci dal ciclo

Il pericolo del ciclo infinito

Se la condizione non diventa mai falsa, il ciclo non termina mai:

# ATTENZIONE: ciclo infinito!
x: int = 1
while x > 0:
    x += 1  # x cresce sempre, la condizione è sempre vera
Per interrompere: Ctrl+C nel terminale.
Per prevenire: progettate correttamente la condizione di uscita.
Un errore molto comune per i principianti. Suggerire di verificare mentalmente che la variabile nella condizione venga modificata nel corpo del ciclo in modo da portare la condizione a False.

for vs while

forwhile

Regola pratica: nel dubbio, provate prima con for.

break e continue

Controllare il flusso dentro un ciclo

break: uscire dal ciclo

break esce immediatamente dal ciclo:

# Cercare un valore
dati: list[int] = [4, 7, 2, 9, 1, 8]
obiettivo: int = 9

for dato in dati:
    if dato == obiettivo:
        print(f"Trovato: {dato}")
        break
4 → no | 7 → no | 2 → no | 9 → trovato! break | 1, 8 mai visitati

continue: saltare un'iterazione

continue salta il resto del corpo e passa all'iterazione successiva:

# Elaborare solo i valori positivi
valori: list[float] = [3.5, -1.2, 4.0, -0.5, 2.1]

for valore in valori:
    if valore < 0:
        continue  # salta i negativi
    print(f"Elaboro: {valore}")
3.5 → elaboro | -1.2 → skip | 4.0 → elaboro | -0.5 → skip | 2.1 → elaboro

Pattern while True + break

Quando la condizione di uscita è nel mezzo del ciclo, non all'inizio:

while True:
    risposta: str = input("Inserisci un numero positivo (0 per uscire): ")
    numero: int = int(risposta)
    if numero == 0:
        break
    print(f"Il quadrato è {numero ** 2}")
Struttura: ciclo infinito con uscita controllata via break. Utile quando servono operazioni sia prima che dopo il controllo di uscita.

Cicli annidati

Un ciclo dentro un altro ciclo

Cicli annidati: esempio

# Tavola pitagorica
for i in range(1, 11):
    for j in range(1, 11):
        print(f"{i*j:4d}", end="")
    print()  # a capo dopo ogni riga
Uso tipico: strutture bidimensionali (matrici, tabelle).
Attenzione alla complessità:
1 ciclo: n operazioni
2 cicli annidati: n² operazioni
3 cicli annidati: n³ operazioni
Se n = 1000, un ciclo annidato esegue un milione di operazioni. Con tre cicli, un miliardo. Questo concetto sarà fondamentale quando parleremo di complessità.

Pattern comuni

Mattoni ricorrenti per risolvere problemi con i cicli

Pattern: Accumulatore

Accumulare un valore (somma, prodotto, concatenazione):

voti: list[int] = [28, 30, 25, 27, 22]

somma: int = 0           # inizializza l'accumulatore
for voto in voti:
    somma += voto         # aggiorna ad ogni iterazione

media: float = somma / len(voti)
print(f"Media: {media:.2f}")
somma: 0 → +28 = 28 → +30 = 58 → +25 = 83 → +27 = 110 → +22 = 132
Schema: inizializzare, iterare aggiornando, usare il risultato alla fine.

Pattern: Contatore

Contare gli elementi che soddisfano una condizione:

voti: list[int] = [28, 30, 25, 27, 22, 15, 12]

sufficienze: int = 0
for voto in voti:
    if voto >= 18:
        sufficienze += 1

print(f"Sufficienze: {sufficienze} su {len(voti)}")
Struttura: come l'accumulatore, ma l'aggiornamento avviene solo quando la condizione è vera. L'incremento è sempre +1.

Pattern: Ricerca

Trovare un elemento specifico:

def contiene(lista: list[int], obiettivo: int) -> bool:
    """Verifica se obiettivo è presente nella lista."""
    for elemento in lista:
        if elemento == obiettivo:
            return True
    return False
Chiave: il return True è dentro il ciclo (uscita anticipata), il return False è fuori (solo se nessun elemento corrisponde).

Pattern: Filtro

Selezionare gli elementi che soddisfano un criterio:

voti: list[int] = [28, 30, 25, 27, 22, 15, 12]

sufficienti: list[int] = []     # lista vuota
for voto in voti:
    if voto >= 18:
        sufficienti.append(voto)

print(f"Voti sufficienti: {sufficienti}")
# [28, 30, 25, 27, 22]
Struttura: lista vuota + ciclo con condizione + append().

Pattern: Min/Max

def trova_massimo(valori: list[float]) -> float:
    """Trova il valore massimo nella lista."""
    if not valori:
        raise ValueError("Lista vuota")

    massimo: float = valori[0]  # inizializza col primo elemento
    for valore in valori[1:]:   # scorre dal secondo in poi
        if valore > massimo:
            massimo = valore
    return massimo
Perché inizializzare con valori[0] e non con 0?
Se tutti i valori fossero negativi (es. [-3, -7, -1]), inizializzando con 0 otterremmo un massimo errato.
Python ha max() e min() built-in, ma è istruttivo capire come funzionano internamente.

Riepilogo dei pattern

PatternInizializzazioneAggiornamento
Accumulatore somma = 0 somma += valore
Contatore conta = 0 if cond: conta += 1
Ricerca (nessuna) if trovato: return
Filtro risultato = [] if cond: .append()
Min/Max best = lista[0] if migliore: best = v
Consiglio: quando affrontate un problema, chiedetevi “quale pattern serve qui?”

Esempio completo

Statistiche descrittive con i cicli

Statistiche descrittive (1/2)

def statistiche(valori: list[float]) -> dict[str, float]:
    """Calcola statistiche descrittive base."""
    n: int = len(valori)
    if n == 0:
        raise ValueError("Lista vuota")

    # Media (pattern accumulatore)
    somma: float = 0.0
    for v in valori:
        somma += v
    media: float = somma / n

    # Varianza (pattern accumulatore)
    somma_scarti_quadrati: float = 0.0
    for v in valori:
        somma_scarti_quadrati += (v - media) ** 2
    varianza: float = somma_scarti_quadrati / n

Statistiche descrittive (2/2)

    # Min e max (pattern min/max)
    minimo: float = valori[0]
    massimo: float = valori[0]
    for v in valori[1:]:
        if v < minimo:
            minimo = v
        if v > massimo:
            massimo = v

    return {
        "n": n, "media": media, "varianza": varianza,
        "minimo": minimo, "massimo": massimo
    }
# Test
dati: list[float] = [23.5, 21.0, 25.3, 19.8, 22.1]
risultati = statistiche(dati)
for chiave, valore in risultati.items():
    print(f"{chiave}: {valore:.2f}")

Prossimamente...

NumPy farà tutto in una riga: np.mean(), np.var(), np.min(), np.max(). Ma ora sapete cosa c'è dentro.

Teorema di Böhm-Jacopini (1966)

SEQUENZA   +   SELEZIONE   +   ITERAZIONE
(istruzioni)    (if/else)      (for/while)

= sufficienti per esprimere qualsiasi algoritmo

Sequenza

Eseguire istruzioni una dopo l'altra

Selezione

Scegliere quale ramo eseguire (if/else)

Iterazione

Ripetere un blocco (for/while)

Risultato teorico fondamentale: con questi tre costrutti di controllo del flusso si può esprimere qualsiasi programma calcolabile.

Lezioni pratiche

  1. Riconoscete i pattern.
    Accumulatore, contatore, ricerca, filtro, min/max — sono mattoni ricorrenti. Quando affrontate un problema, chiedetevi: “quale pattern serve qui?”
  2. Capite cosa c'è sotto.
    La funzione statistiche() usa solo cicli e condizioni, eppure calcola media, varianza, minimo e massimo. Non è magia: è un ciclo con un accumulatore.
Prossima lezione: comprehension (un modo elegante di esprimere filtro e trasformazione) e stringhe come struttura dati.
