Il primo programma

Hello World, indentazione, commenti

Hello, World!

print("Hello, World!")

In questa riga ci sono tre elementi da notare:

  • print è una funzione built-in. Le funzioni si chiamano con gli argomenti tra parentesi.
  • "Hello, World!" è una stringa: sequenza di caratteri tra virgolette (" o ', equivalenti in Python).
  • Niente punto e virgola: di norma ogni istruzione occupa una riga.
Tradizione resa popolare da Kernighan e Ritchie nel libro "The C Programming Language" del 1978.

L'indentazione come sintassi

Altri linguaggi (C, Java...)

I blocchi sono delimitati da {}

L'indentazione serve solo alla leggibilità

Python

L'indentazione fa parte della sintassi

Stabilisce quali istruzioni stanno dentro un blocco

if temperatura > 30:
    print("Fa caldo!")             # dentro l'if
    print("Accendi il ventilatore")  # dentro l'if
print("Fine del programma")       # fuori dall'if
Convenzione (PEP 8): 4 spazi per livello di indentazione, senza tabulazioni.
Scelta di Guido van Rossum: obbliga a indentare in modo ordinato. Indentazione incoerente: IndentationError. Istruzione al livello sbagliato: il programma parte ma fa altro (es. togliere i 4 spazi al secondo print lo porta fuori dall'if). L'if si vede in T08; qui serve solo come esempio di blocco.

I commenti

Iniziano con # e vengono ignorati dall'interprete:

# Questo è un commento su una riga intera
temperatura: float = 23.5  # Commento a fine riga
Un commento utile spiega il perché di un'istruzione; che cosa fa si legge nel codice. 
i = i + 1  # incrementa i di 1
i = i + 1  # salta l'intestazione del CSV

Variabili e assegnamento

Nomi, oggetti, assegnamento

Scatole o etichette

"Le variabili sono scatole che contengono valori"

"Le variabili sono etichette attaccate a oggetti"

In Python l'operatore = attacca un'etichetta (il nome) a un oggetto; il modello a scatole è impreciso.

Etichette in azione

x: int = 42     # crea l'oggetto 42, attacca l'etichetta x
y: int = x      # attacca l'etichetta y allo STESSO oggetto
print(x is y)  # True: sono lo stesso oggetto
Questo modello servirà con liste e mutabilità.
is restituisce True se i due nomi si riferiscono allo stesso oggetto. Non viene creata una copia: y diventa un'altra etichetta attaccata allo stesso oggetto. Sia x che y puntano al medesimo 42.

L'operatore di assegnamento

= è l'assegnamento. Non è l'uguaglianza matematica (per quella c'è ==).

contatore: int = 0          # contatore punta a 0
contatore = contatore + 1   # contatore ora punta a 1
# In matematica "x = x + 1" non ha soluzione;
# qui: calcola contatore + 1 e ricollega il nome.

Operatori di assegnamento composto

contatore += 1   # equivale a: contatore = contatore + 1
totale -= 10     # equivale a: totale = totale - 10
prodotto *= 2    # equivale a: prodotto = prodotto * 2

Assegnamento multiplo e unpacking

a = b = c = 0        # tre nomi, stesso oggetto 0
a, b, c = 1, 2, 3    # unpacking: a=1, b=2, c=3

Scambio di variabili

In altri linguaggi:

temp = a
a = b
b = temp

In Python:

a, b = b, a  # ora a=2, b=1
A destra si costruisce una tupla, poi i valori vengono assegnati ai nomi a sinistra (unpacking). In queste forme non si possono mettere type hints: a: int = b: int = 0 è un SyntaxError.

Naming conventions (PEP 8)

Elemento Stile Esempio
Variabili e funzioni snake_case media_voti, numero_studenti
Costanti UPPER_SNAKE_CASE SOGLIA_SUFFICIENZA, PI_GRECO
Classi PascalCase StudenteUniversitario
Evitate: l (elle), O (o maiuscola), I (i maiuscola) — si confondono con 1 e 0.

Nomi significativi

Il nome di una variabile è una forma di documentazione:

x: float = sum(z) / len(z)

Cosa significano x e z?

media_voti: float = (
    sum(lista_voti) / len(lista_voti)
)

Il codice si spiega da solo

Eccezioni accettabili: i, j, k per indici di ciclo; n per dimensioni — dove la convenzione matematica è chiara.

Tipi di dato fondamentali

Python è tipizzato dinamicamente

Il tipo appartiene all'oggetto

In Python, il tipo appartiene all'oggetto, non alla variabile:

x = 42        # x punta a un int
x = "ciao"    # ora x punta a una str (è consentito)
Vantaggi
Flessibilità, codice conciso, prototipazione rapida
Rischi
Errori di tipo scoperti solo durante l'esecuzione
Nel corso annotiamo il tipo atteso con i type hints.

Type hints: il nostro approccio

Senza type hints

eta = 25
nome = "Mario"
media = 27.5

Con type hints

eta: int = 25
nome: str = "Mario"
media: float = 27.5
iscritto: bool = True

I type hints non vengono controllati dall'interprete, ma:

  • Rendono il codice più leggibile
  • Permettono la verifica con strumenti come mypy
  • Obbligano a decidere il tipo di ogni variabile

int — Numeri interi

eta: int = 25
popolazione: int = 59_000_000   # _ separa le migliaia (ignorato)
temperatura: int = -5
Precisione arbitraria: nessun overflow, il limite è solo la memoria disponibile. 
grande: int = 2 ** 100
print(grande)  # 1267650600228229401496703205376
In C o Java un intero ha un numero fisso di bit (32 o 64) e quindi un valore massimo; in Python no. La rappresentazione degli interi si vedrà in T05 (rappresentazione dei dati).

float — Numeri in virgola mobile

altezza: float = 1.75
pi: float = 3.14159265358979
temperatura: float = -2.5
notazione_scientifica: float = 6.022e23  # 6.022 x 10^23
IEEE 754, doppia precisione (64 bit, circa 15-16 cifre significative). 
print(0.1 + 0.2)       # 0.30000000000000004
print(0.1 + 0.2 == 0.3)  # False

0.1 non ha una rappresentazione binaria esatta: il motivo si vedrà in T05.

str — Stringhe

nome: str = "Anna"
cognome: str = 'Rossi'        # virgolette singole: equivalenti
messaggio: str = "Ciao, mondo!"
multilinea: str = """Questa stringa
occupa più righe"""
  • Sequenze immutabili di caratteri Unicode
  • Virgolette doppie " e singole ' sono equivalenti
  • Triple virgolette """ per stringhe multilinea
Le approfondiremo in una lezione dedicata.

bool — Booleani

iscritto: bool = True
esame_superato: bool = False

True e False si scrivono con l'iniziale maiuscola.

bool è un sottotipo di int. True vale 1, False vale 0. 
print(True + True)   # 2
print(True * 10)     # 10
print(False + 5)     # 5

Motivo storico (compatibilità con il codice che usava 1 e 0); permette di contare i valori veri con sum().

None — L'assenza di valore

risultato: None = None

None rappresenta l'assenza di valore.

None è diverso da:
  • lo zero (0)
  • la stringa vuota ("")
  • False
È l'unico valore del tipo NoneType.

Le funzioni che non restituiscono esplicitamente un valore restituiscono None.

Riepilogo dei tipi fondamentali

Tipo Descrizione Esempio
int Numeri interi (precisione arbitraria) 42, -5, 59_000_000
float Numeri in virgola mobile (64 bit) 3.14, -2.5, 6.022e23
str Stringhe (immutabili, Unicode) "ciao", 'mondo'
bool Booleani (sottotipo di int) True, False
NoneType Assenza di valore None

Introspezione e conversioni

Conoscere e trasformare i tipi

La funzione type()

Per verificare il tipo di un oggetto a runtime:

print(type(42))         # <class 'int'>
print(type(3.14))       # <class 'float'>
print(type("ciao"))     # <class 'str'>
print(type(True))       # <class 'bool'>
print(type(None))       # <class 'NoneType'>
La funzione type() restituisce il tipo dell'oggetto a cui punta la variabile, non della variabile stessa (che non ha tipo).

Conversioni di tipo (casting)

# Da stringa a numero
eta: int = int("25")           # 25
altezza: float = float("1.75") # 1.75

# Da numero a stringa
testo: str = str(42)           # "42"

# Da int a float e viceversa
x: float = float(42)           # 42.0
y: int = int(3.99)             # 3  (tronca, non arrotonda)
int(3.99) restituisce 3, non 4: tronca verso lo zero (int(-3.99) è -3).

Conversione a bool

Ogni valore può essere convertito in True o False:

Espressione Risultato Regola
bool(0) False Zero è falso
bool(42) True Qualsiasi numero diverso da 0
bool("") False Stringa vuota è falsa
bool("ciao") True Qualsiasi stringa non vuota
bool(None) False None è falso
Regola generale: zero, vuoto e None sono falsi; gli altri valori sono veri.

Tutto è un oggetto

In Python ogni valore è un oggetto, anche i numeri:

print((42).bit_length())    # 6 (servono 6 bit per 42)
print((-7).bit_length())    # 3
print("ciao".upper())       # CIAO

Ogni valore ha attributi e metodi — funzioni associate all'oggetto.

I metodi si chiamano con la notazione col punto: oggetto.metodo().
Questo è diverso da linguaggi come C dove i tipi primitivi non sono oggetti. In Python non esistono "tipi primitivi" nel senso tradizionale.

Esempio: Celsius → Fahrenheit

celsius: float = 25.0
fahrenheit: float = celsius * 9 / 5 + 32
print(f"{celsius}°C = {fahrenheit:.1f}°F")
# Output: 25.0°C = 77.0°F
f"..." è una f-string: permette di inserire espressioni Python tra {}.
:.1f formatta il float con 1 cifra decimale.

is e ==

# nella shell interattiva, una riga alla volta
a: int = 256
b: int = 256
print(a == b)   # True  (stesso valore)
print(a is b)   # True  (stesso oggetto)

c: int = 257
d: int = 257
print(c == d)   # True  (stesso valore)
print(c is d)   # False (oggetti diversi)
CPython tiene in cache gli interi da -5 a 256 (integer caching); oltre crea oggetti nuovi. Eseguito come script, c is d può dare True.

Per confrontare valori si usa ==; is confronta l'identità.
